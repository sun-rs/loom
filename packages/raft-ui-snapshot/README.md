# Historical Raft UI reference evidence

This private package preserves an immutable snapshot of the temporary `raft-ui`
reconstruction. It is not official React source, a product dependency, a generator
input or the authoritative RAH standard. Its manifest records original Git
identity, dirty state, file sizes and hashes. Historical statements inside the
snapshot are not current product claims.

RAH maintains the [Neo-Brutalist UI library](../../docs/design/neo-brutalist-ui.md).
Initial adoption references this evidence; do not repair production by editing
the snapshot. Its HTML/reference adapter can support explicitly labeled
historical comparisons, never a live product path. Original notices remain intact.

`npm run ui:snapshot:check` checks integrity. No importer or product regeneration
command depends on an external checkout.
