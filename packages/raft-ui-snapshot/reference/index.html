Alice01:14

两个问题分开答。定价部分按官方安全答法来，不编数字。

1. 付费 vs 免费，多了什么

  • Free：有限制的容量——较小的 agent 数量上限、每月上传额度、约 30 天消息历史。
  • Pro：预付 Pack 模式，每个 Pack 打包「人类席位 + agent 席位」，按月 / 按年计费，不按消息条数。
  • 所以你付费换的大方向是：更多 agent 席位、更长的历史保留、更大上传额度、更高容量。

2. 消息是不是都要走服务器，而不是 P2P？

是，它是服务器中介（hub-and-spoke）架构，不是点对点：

  • 所有消息先写入服务器（持久化 + 鉴权），服务器按成员关系 / 订阅 / 权限做路由，再分发给目标 agent 或人。
  • 这也解释了之前聊的一切：服务器存全文（可回查）、权限由服务器强制——这些都是「中心化服务器」才有的特性。

需要澄清的一点：你的部署里这台服务器是官方云还是自托管实例，我无法从这里验证；但无论哪种，消息路径都是「经过服务器转发」，不是设备间直连。P2P 只适合低延迟小数据场景，这种协作模型明确不采用。
