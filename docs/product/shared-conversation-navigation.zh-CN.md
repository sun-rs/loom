# 搜索、动态、聊天的导航与折叠合同

2026-09-20：用户确认后，先设计再实施。此合同取代旧搜索预览“任意关闭都清空预览”和旧分栏“父页隐藏即返回”的规则。

## 状态与唯一 owner

App 的 Room、Thread、profile intent 与搜索预览 URL 保持导航所有权，不另建业务数据栈。`conversationPanels` 选择最新目标和真实来源；`conversationLayout` 与其测量 hook 只计算呈现。连续栏宽状态归 `ConversationLayoutShell`，只把离散折叠模式交给 App；稳定 children 不随拖动重建。容器观察器不随栏宽重新订阅。消息、草稿、虚拟滚动和任务状态仍归原 owner。设置抽屉内部导航不参与主内容分栏。

路径可以是列表→频道→消息列→资料，共四层；最多同时显示列表及最后两个内容层。直接从结果打开消息列时，路径是列表→消息列→资料，不能补造频道。关闭最右层只移除该层；被宽度隐藏的来源保留。重新放大只恢复仍打开的层。

## 几何与按钮

所有尺寸按实际可用宽度计算，窗口高度、横竖屏和 PWA 显示模式不参与决策。沿用现有来源参数：聊天列表 180–320，搜索/动态宽档 400–720（默认 560）、紧凑档 320–480（默认 320），中间正文最低 320，右栏最低 360；主内容单页断点 768。这些值来自既有源码证据，不是截图估算。

三栏时保留列表与右栏偏好，中间吸收余量；不足 320+360 时隐藏中间。两栏列表按原宽/紧凑档有界缩放，不能挤压最右内容低于 360。低于单页断点只保留最右层。拖拽偏好不被折叠写回覆盖。

| 呈现                  | 最右层按钮 | 退出结果           |
| --------------------- | ---------- | ------------------ |
| 列表+来源+子页        | X          | 关闭子页，恢复来源 |
| 列表+子页（来源隐藏） | X          | 关闭子页，恢复来源 |
| 子页独占              | 返回，无 X | 恢复直接来源       |
| 列表+一级内容         | X          | 恢复列表           |
| 一级内容独占          | 返回，无 X | 恢复列表           |

设置抽屉可以同时存在返回和 X：前者回抽屉上一页，后者关闭整个抽屉。任务弹窗及列表/看板不改变其既有 owner。主内容按钮的语义不依赖内容类型。

## 输入、异步与恢复

缩放不发起导航、不新增 history、不重新加载内容、不清除草稿、筛选、选中状态及滚动锚点。隐藏页面保留挂载与有效测量，并 inert，禁止抢焦点。打开请求沿用 navigation generation，关闭或另一入口导航后迟到结果不得覆盖当前页。显式跳转可离开来源大页；普通打开保持来源大页。

## 验收矩阵

- 搜索/动态/聊天：频道及私聊→消息列→Agent/Human，宽→中→390→宽，最多三栏。
- 搜索/动态直接消息列→资料→消息列→列表，不插入频道。
- 中档 X 和单页返回退出相同一层；关闭后放大不复活。
- 同宽不同高呈现相同；保留 Room/Thread 草稿、资料编辑及滚动。
- 设置抽屉返回与 X 不回归；迟到导航、拒绝访问沿用现有保护。
- 自动测试、隔离浏览器、正式部署及上游双边验收分别记录，未运行不宣称通过。

## 旧消息列闪烁与空白修复

搜索命中旧消息列时，消息上下文可能在已加载的频道最近一页之外。此前 Room 后台刷新用该页缺少根消息来清除 `activeThreadRootMessageId`，随后 `message.context` 又恢复它，导致反复卸载/挂载；若定位的是根消息本身，则可能保持空白。人员侧栏的来源也会在这期间错误回退，放大了分栏异常。

修复只移除“分页消息缺席即关闭导航”的副作用：后台刷新继续更新 Room 投影，当前消息列仅由显式导航及 Room 切换改变。未加载不等于已删除，分页结果不是导航 owner；沿用现有有界历史、权限检查及消息上下文，不加载全部历史。

新增 `test-search-history-stability-browser.mjs`：无 Agent 的隔离频道，旧根与回复后追加 65 条频道消息，通过真实搜索结果打开。DOM 观察器先复现根节点被卸载，修复后跨至少三次后台读取保留节点、草稿与可见内容；覆盖 1600/900/390、人员资料关闭、直接旧根消息列以及关闭后不复活。纳入 `test:web:shared-navigation`。

此修复 Chromium、Firefox 历史稳定性回归、共享导航回归及类型检查通过，正式构建与 diff 检查通过；全仓 check 仍止于已有未登记接口，format 仍有上述 5 个已有告警。已验证状态备份后重启正式工作台，冻结 build `904cb1bd5a29a4e3eb8ee2cad0029bdb8d2c78ce03d91eb57fd92d9aaefeae15`。正式浏览器通过真实 Kimi 搜索的旧消息列连续三轮读取无卸载，并检查 1600/900/390 缩放、Human 资料及已删除 Gemini 的不可用资料面板、关闭恢复。最初尝试按截图的“到岗”摘要选项定位未匹配当前结果，改用实际存在的旧消息列；不声称复现了截图同一条消息。正式验收只读，未发送消息或运行付费 Provider。
