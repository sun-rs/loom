## 明确不在本轮隐式改变的产品决策

- Agent管理员权限、restart/reset破坏性语义、远程Computer注册/升级是单独设计门槛；按钮仍应如实disabled并解释原因，不能为了同款外观假装有功能或扩大ACL。
- 默认头像点击打开动态沿用户要求；官方可自定义tab顺序，不把单个账号偏好升级为统一硬规则。Computer首次本地自动选择作为显式本地选择保留，不称无条件复制官方。
- Enter发送、Shift+Enter换行统一用于Room/DM/Thread；IME/候选确认不发送。管理表单不继承此快捷键。
- 不复制Raft中央服务器、账号/计费或Provider安装器。今后远程Computer只替换文件/运行时owner的传输，不更换产品合同。

## 验收与发布

浏览器追加反例也属于本批：InputRequest 异步出现不能依赖 reload；Activity 打开 Thread 应保留列表背景与筛选；保留挂载后仍须释放所属 action 的 pending，不能清新 action；筛选改变/清除不能覆盖或复活旧 Thread URL；offline 状态须一致覆盖 Computer、Member Host、Agent 头像/资料/DM；系统通知在移动端也须可见，打开通知不隐藏其待处理点。上述读模型/导航保护不增加业务状态机，不改变 Task/InputRequest 的 canonical owner。

每个行为先写失败测试再施工，保留现有工作树。代码门禁为 `npm run check`、`npm run format:check`、`git diff --check`；普通构建只写隔离输出。流程测试使用临时DB/端口/Fake Runtime，无付费CLI。

浏览器使用Browser技能：1440×900、DPR1双边取证；本地再测390×844。覆盖粉/灰点、hover/Escape/头像/姓名、Room/DM/Thread Enter、通知生命周期、动态定位、文件树和快速切页。官方只读导航，未取得非空在线目录/系统通知样本的项标“源码合同+本地通过”，不冒充双边通过。

正式后端重启需用户允许；重启前确认无活动任务，保存一致性备份，保持身份/模型/记忆/Room不变。新页入口、资产版本与登录后主页面都必须验证。若未获重启授权，交付明确区分代码/隔离验收与正式部署状态。

最后由未参与实现的subagent独立审查代码及浏览器结果，按反例驱动修复后再审。最终报告逐项列“已修+证据”“明确产品差异”“未测/未完成”，不写全站100%或无分母的完成率。
