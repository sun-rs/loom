## 固定执行范围

`node scripts/test-cli-business-long.mjs --plan --pair=1` 只读取本地版本及源码信息，不调用模型。付费入口为相同参数中的 `--paid`，仅在对应批次获授权后使用。每次只运行一个编号配对，拒绝 `--pair=all`、缺编号、重复或未知参数；不存在循环跑四批、失败补跑或挑成功样本的入口。

| 项目           | 固定条件                                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------------------- |
| CLI / 模型     | Codex 0.160.0，gpt-6-luna / low；每次实际启动核验                                                             |
| 每个配对       | 两臂各三个独立连续 session，每人十二轮，36 个阶段；合计 72 阶段                                               |
| 四批预定顺序   | 1 原生→Loom；2 Loom→原生；3 原生→Loom；4 Loom→原生                                                            |
| 任务           | 既有 inline 固定源码事实题，十二题；完整材料每 session 首次一次，后续仅实际历史                               |
| 原生记忆       | 每次初始/续聊关闭 provider 自动记忆；正常历史保留                                                             |
| 平台记忆       | 新临时频道在实例创建前，通过 Human API 关闭读与写，读回并查询持久状态；后续每次抓取证据继续检查默认与成员覆盖 |
| 单臂资源止损   | 输入 1500000 token、1200000 ms（20 分钟）；产品臂最多 72 个 RunAttempt                                        |
| 全研究计划上限 | 四对合计输入 12000000、臂时间 160 分钟、产品 RunAttempt 288；不构成整批授权                                   |

这些上限是准入软限，不是合同预算、预计花费或账单封顶。在途请求可能越过输入上限，实际溢出仍保留。P121 产品六阶段 98453 输入，按阶段数简单放大约 59 万仅用于选择保守止损量，不预测长历史成本。较旧长测的 360 万/40 分钟单臂上限收紧，不以达到上限作为目标。

每批 plan 记录 pair index、顺序、任务/指令/答案表哈希、平台记忆条件、模型/CLI 和资源限制。代码须已提交且工作树干净；实际 `codeCommit` 随批次冻结，无法把修复前后两次运行拼成同一研究。四批是探索性重复，不能仅凭这四批宣称一般稳定性。

## 继续与停止

普通答错、明确拒绝后合法恢复、额外生成、MCP/CLI 合法路径变化和单轮合同失败均保留费用，在安全与资源条件内继续。每个后续阶段收到本臂真实历史，禁止人工回填正确答案。

未知写入结果、越权/错目标/重复写入、无法核验的工具副作用、身份/源码/记忆漂移、缺失用量或 ACK、资源边界则停止后续准入。已补 `RESULT_UNKNOWN` 的明确 MCP 回执阻断测试；不把它当普通拒绝后继续。停止前已发生的成本不会删除或填零。

当前“安全结束但无规范回复”的终态仍保守停止，尚未实现所有可继续分支。动态或不支持的工具 wrapper 仍可能造成观测证据不足；不能把它报告成模型业务能力失败，也不会为了继续研究执行模型代码或放宽权限。

## 输出与限制

每个参与者首次、第 4/8/12 轮累计报告输入、缓存、未缓存、输出、已报告生成、质量与交付。总比值来自同范围累计量，不平均单轮比值，不扣除模型错误成本。平台账与原生轨迹交叉核对，同一费用不重复累加。

质量全通过且证据完整才有等质量比较资格；否则仍展示全部成本与质量缺口。合同 §6 单独裁决，不因累计比值较低抵消单项失败。事实题允许看到同伴答案，只测传输，不证明协作价值、独立理解或开放任务能力。

[免费完整链路](evidence/2026-10-06-business-long-free.md)验证三会话十二轮、合法恢复、错误原文继续、末轮恢复与记忆开关。合成模型及合成用量只能证明程序测量路径；不能替代本批之后的真实模型运行，也不计入付费研究分母。

## P121 记忆条件补充

P121 的 CLI 自动记忆关闭证据成立，但平台频道没有持久策略行或成员覆盖，实际采用默认读写开启；条目为零。因此只能说“空平台记忆库，没有已知条目投递”，不能说平台读写被关闭。这不改变其实际用量、答案、交付或效率失败裁决。新长期 profile 显式冻结关闭条件，身份与 P121 不同，不直接拼接样本。
