# 独立单聊与频道内私密消息入口

2026-10-19 按负责人已批准的“独立单聊＋频道实例私密消息”实施。保留 Room-first 合同，不新增会话种类，不把现有 private box 转换为独立 session。

- **独立单聊**：从 Agent 的 Role 详情“开始独立单聊”创建普通 Channel，再通过既有 `role.instantiate` 创建新实例。实例、会话绑定、工作目录和 Channel 记忆均使用原有所有者；不会复用其他频道实例。普通聊天／任务／工作区标签保留。每次确认创建新会话；已有会话从侧栏或实例列表进入。
- **展示分类**：Human × Workspace 的 `human_sidebar_preferences` 是唯一持久化所有者。`dmOrder` 的 `room:` 键明确表示独立聊天展示，`peer:` 历史键保留兼容。它不改变 Room.kind、成员权限或执行策略，也不按名称／人数推断分类；以后添加成员仍走普通频道合同，不承诺永久限制一个实例。
- **私密消息**：原来的 private box 不再放在顶层聊天侧栏。频道成员行可打开当前实例的私密消息；频道设置的“私密消息”列表直接打开已有 Room，包含已移除实例的只读历史。`instancePrivateBox.channelId` 是 Kernel 从既有实例记录提供的只读来源字段，旧客户端允许缺失；它不授予读取来源频道的权限。旧链接和搜索结果仍有效；Agent 实例列表只打开所属频道，不另设私密消息入口，不删除记录或修改冻结配置。
- **失败边界**：创建依次执行频道、实例、个人侧栏分类，每步确认成功后继续。未知结果通过原 `WriteIntentSlot` 核实相同请求；已知失败可显式继续，不重新创建成功步骤。浏览器关闭／刷新不恢复这个临时向导，部分完成的频道仍在正常频道目录中可管理，不自动回滚或删除。分类失败不代表实例创建失败。
- **关闭／重开**：关闭单聊仅写个人 `hiddenDms`，不移除成员或关闭实例。再次通过实例列表／已有链接打开时按官方 `reopenRouteDm` 行为恢复侧栏；新未读仍可使隐藏会话显示。版本冲突显示失败，不自动无限重试。

官方依据：已锁定 Raft v1.21.22 生产资源，以及授权源码 Sidebar 的 DmRow、reopenRouteDm 和 Agent 打开聊天入口。沿用原生 SidebarItem、AvatarSlot、PanelHeader、Dialog 和成员行。Role 新建实例向导／频道私密历史是 Loom 语义组合，不宣称它们是官方逐字复制。完整来源和差异记录在 `frontends/raft/page-adoption.json` 的 `standalone-chat-entry`。

本批不改变调度、提示词、CLI adapter、自动记忆、Fork／Side 合同，不启动付费 CLI 或重新打开效率实验。后端仅接上原本缺失的来源投影与既有个人侧栏对普通频道的分类兼容；数据库 schema 不变。
