# 移除旧全局 #all 设计

Owner 指出上一轮清理错误保留了 `#all`。该保留是历史规则残留，不符合当前 Role → 频道实例架构；上一轮记录的例外不再是产品目标。

根因不只是前端：启动器会创建/恢复 `#all` 并设为默认频道；Kernel 自动补旧 Workspace Agent 成员；创建、改名、归档、退出、删除和前端菜单均有 slug 特判；管理页仍提供隐藏系统频道操作。

本次移除上述生产路径和旧系统频道 API。新数据目录只建立工作区控制 Room，不生成 `#all` 或 Agent Council；用户创建频道后再创建其成员实例。`all` 不再是保留名称，若用户主动创建则与其他频道相同。旧导航 defaultRoomId 可读，但频道已删除时清除指针，不阻止重启、不补建频道。不会自动删除其他安装环境已有频道及其历史。

删除 ensure-all-channel、自动成员修复、系统频道可见性业务服务和 UI 适配；生成组件通过生成器移除系统频道导出，未改不可变上游源。历史数据库字段、事件和协议 schema 留作兼容数据读取；历史 first-run 回执处理保留，但不再生成全局自我介绍请求。`@all` 的频道内广播语义不变，它与名为 `all` 的频道无关。

原“永久频道必须存在”测试改为：可创建普通私有 all、改名、归档、删除、Kernel 重启不复活；新/旧 Workspace Agent 均不自动加入 all。启动测试证明：零频道冷启动、删除旧默认频道后两次重新准备仍为空。产品 UI 合同验证不再挂载隐藏入口或调用旧 API。旧付费 gate 改用明确的测试专用频道夹具，不依赖产品自动播种；本轮不运行付费 gate。

71项定向免费检查、根目录和前端类型检查、正式构建通过。顺带修正 Core API 清单测试遗漏的三个已存在接口（本地通知、Role 恢复、记忆更新），未为这些接口新增行为。正式部署/删除/重启计数见 summary.json。此前清理证据保持原样，本记录纠正其保留 #all 的结论。

正式服务已通过 Human API 删除遗留 `#all`，精确重放成功；随后优雅重启，仍为0频道、0实例，只保留内部控制 Room。桌面与手机新页面均无 `all`，管理页无旧设置请求/脚本错误。发现并修复了空频道列表在移动端隐藏创建入口的连带缺陷：仅“频道”分区即使为空也保留原生＋，未改变其他空分区规则；先失败后通过的定向断言和正式手机点击确认可打开新建频道窗口。
