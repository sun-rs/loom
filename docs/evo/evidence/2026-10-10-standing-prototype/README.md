# 按回复模式组织常驻指令：私有候选结果

2026-10-10，基于 `05cccd1`。本轮实现并验证了一个隔离源码候选，**没有合入产品代码、没有部署、没有付费模型请求**。它只调整 daemon 编译器的平台操作和启动收尾两层，原生回复驱动、Kernel、权限、消息交付和会话存储不变。角色、自定义指令、记忆及其余层逐字保留，默认模式在 delivery × Role × memory 组合中与原版输出和摘要完全一致。

## 实际结果

使用与[上一批](../2026-10-10-fixed-transport-replay/README.md)相同的固定文件读取和最终回答轨迹；Pi 双臂、Kimi 三臂，每臂新建独立会话并连续 12 轮。所有响应来自 localhost 合成服务。每臂仍为 24 次请求，没有新增请求；这只能验证固定脚本下的传输行为，不能证明真实模型的指令遵循。

| CLI / Loom 路径 | 原版累计请求体字节 | 候选累计请求体字节 |   减少 | 相对原版 Loom |
| --------------- | -----------------: | -----------------: | -----: | ------------: |
| Pi              |            408,382 |            396,238 | 12,144 |         2.97% |
| Kimi ACP        |          2,398,882 |          2,386,882 | 12,000 |         0.50% |

Pi 原生累计 212,958；Kimi print 2,232,965、共享 ACP 桥 2,201,754。控制臂各对应请求的字节长度不变，但新会话、路径等字段变化，不能说完整请求内容逐字节相同。工具定义、设置、wake 包装等可比性另见原始结构审查。Kimi 工具结果仍含动态耗时前缀。

**以上全部是 UTF-8 JSON 请求体字节，不是 token、未缓存输入或金额。** 同一输入的编译结果净减少 496 字节：平台层减少 1,129，明确收尾与回退的启动层增加 633。实际 Pi 每请求序列化减少 506 字节，含独立运行环境的细小差异；Kimi 每请求减少 500 字节。正文大小、JSON 转义和运行身份差异分别记录，不能混称纯文案删减。

## 验证及修正

候选经历先红后绿；8 项新增测试、59 项既有常驻提示测试及 12 项既有运行时专项通过。实际 Pi/Kimi 共 120 请求、60 次真实文件读取及五条连续会话，逐请求捕获和进程清理另外审查。源码变更、原流哈希与限制保存在下列证据。

审查中修正了三个会影响结论的点：

- `target`、`based-on-room-seq`、`final` 限定于相应回复命令，不能让所有 Worker 工具都携带这些参数。
- 禁止的是额外 Room 命令包装，不能禁止用户要求的 JSON 或 CLI 参数正文。
- Role 实例刻意忽略提示摘要变化来保持同一 session；摘要不是旧会话迁移门禁。本实验仅由 runner 独占新数据目录、创建新实例/会话，不修改产品连续性规则。此前相反的设计判断已在独审中撤回。

多目标、截断、无需回复以及未选择 native-final 的唤醒保留 Worker 回退说明；当前 wake 的 native-final 选择明确为通用帮助中回复说明的条件例外。文本断言与固定模型响应不构成真实模型遵循这些边界的证明。旧 session 升级、跨版本帮助覆盖、其他 CLI/模型、压缩及多人协作均未验收。

## 决定

本候选的直接传输收益有限，**不作为成本优化发布，不继续以压缩文案为当前主线，也不因字节下降宣称效率达标**。保留可审查 patch；其中措辞澄清是否改善真实模型行为仍未知。候选的 mode 专用规则若将来进入产品，还需要回归覆盖与已有会话升级设计。

下一项调查应针对此前付费轨迹中的额外业务请求：先用已有完整捕获列出具体修错触发、后续重复携带的历史以及两臂差异，提出单一可验证干预；没有这样的假设，不为这个小幅字节改善扩大付费批量。沿用已修好的用量采集和 v6 质量夹具，所有失败和消耗继续留账；不把业务差异全部称随机性，也不从总消耗扣掉它们。
