## 两次流程，分别裁决

**首次流程：有恢复的完整闭环。** OpenCode 同一消息点名两位成员，二者的普通回复不符合现有单收件人自动返回范围，讨论停顿。Human 一次性澄清边界后，沿原实例及 session 继续；没有提供代码解法或评审发现。AGY 实际编写运行 12 项独立检查；Claude CLI 发现全局拒绝 JSON float 导致取消行／无关字段被提前拒绝的真实缺陷。OpenCode 修复并补回归，Claude CLI 复跑失败用例和 37 项测试后接受，协调者交付，外部 40/40。它不判无人干预通过。[原结果](assisted-summary.json)、[原评审发现](assisted-quality.json)。

**修正后固定回归：全新 session，无恢复。** 保留首次全部费用，在同一批总预算内固定追加一组新隔离工作区；其运行时通信说明及任务说明均与现行协议一致，二者的单独因果效果没有做 A/B 隔离。初始 Human 只点名 OpenCode，后续设计意见、等待、实现、评审与最终交付由成员自行完成。OpenCode 实现 Decimal 动态高精度汇总和 32 项测试；Claude CLI 独立新增 6 项检查，包含 30 组固定种子随机输入与 Fraction 参照比较、2000 行最大数值聚合精度；AGY 独立新增 15 项 API/CLI 检查。两位都读取实际文件、运行测试并明确接受，OpenCode 最后自行重跑三个测试套件并交付。外部 40/40，无错误 Run，无人工接力，三家各一个连续原生 session。

模型与测试也有自身误差：首次 AGY 提出的 `Decimal(str(Fraction))` 建议不普遍有效，实际实现规避；新回归中 Claude CLI 自己的独立参照辅助函数先有差异，随后自行定位修正并重跑，不作为实现缺陷。保留原流，不把中间错误隐藏成全程一把通过。

## 两项修正与证据

1. **AGY 目录限时。** 免费准备保留两次失败：私有包装器路径错误、AGY 明确模型目录为空；均在付费提示前被拦住。`agy models` 联网刷新，原统一 5 秒限时在实际约 5–6 秒的边缘；5.2 秒假 CLI 在旧代码上被终止，可稳定复现。默认 AGY 限时改为 15 秒，显式更短限时仍生效。15 项相关测试、root typecheck 通过，随后免费完整准备成功、0 生成。[时长对照](agy-timeout-control.json)。这修正一个具体截断原因，不承诺离线和任意网络异常都有目录。
2. **native-final 通信说明。** 保持 Kernel 原有因果、幂等和单跳边界：只有一个已实际投递且只点名当前实例的普通顶层请求可派生返回；多人点名或多来源继续显式指定请求者，自动返回不再自动产生下一跳。说明同时要求状态／确认类信息用普通名字，避免无意 @ 唤醒。新增两项红转绿测试，六项 native-final 检查通过，新 session 已完成本次功能实测。没有扩大自动投递范围，也没有新增调度队列。
