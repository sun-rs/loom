# 消息投递显示精简：连续目标标题与内部字段

开始：2026-10-06；验证：2026-10-07。承接[上游设计研究](2026-10-06-upstream-context-design.md)及[成功回执精简](2026-10-06-compact-mcp-receipt.md)。本批无付费模型调用。

## 实现与不变量

`packages/agent-host/src/worker-read-render.ts` 单独拥有紧凑唤醒文本投影。连续事件只有完整 Room ID、完整 Thread ID 和显示目标均相同时才共享 `Target:` 标题；每次渲染重新分组，不跨 catch-up / For you 边界，不重排事件。单条、目标变化、完整身份不同（即使短引用碰撞）、UTF-8 字节不严格减少时保留原逐条格式。

每个事件的正文、序号、作者、消息引用、mentions、附件及评论后缀保留。Reply context、任务/notice补读、重试、异常恢复和 memory 展示未改。仅 `instance.created` 隐藏顶层 `provisionEventId` / `requestDigest`，完整实例、未知字段和其他事件保留；原始输入不修改，完整 Worker 读取、Kernel 事件与消费状态保持原样。没有修改原生 session 已存历史，无新状态/游标/摘要模型；本地实现，无上游代码复制。

## 字节预算与边界

基于此前72份真实请求的离线预算：36次新wake，连续目标标题减少1,620字节，创建事件内部字段减少486字节；包含历史重复呈现时分别减少10,530和5,832字节，合计16,362字节。通过持久事件重建并精确匹配事件区块，只改renderer拥有的前缀与指定字段，不搜索替换正文。该样本为同一顶层目标，Thread/混合目标由确定性测试另验。这是历史请求上的表示反事实，不是新旧模型配对，不提供token或费用比例。

私有可复算预算：`~/.loom/reviews/2026-10-06-target-header-byte-budget/`。真实模型质量、缓存、长期效率仍需独立配对；既有P122未验收结论保持。

## 免费实际链路

[新链路审计](2026-10-06-compact-wake-projection.json)、[旧请求预算](2026-10-06-compact-wake-budget.json)。隔离的已安装 Codex 0.160.0，原生自动记忆关闭，无继承账号，唯一端点为 localhost 合成模型。三个连续 session 各两轮，六次真实 HTTP、六条唯一 Room 回复/marker/同 consumer ACK。每个新wake的补读四事件实际共享标题，For-you单条仍显式指明目标。以相同持久事件/addressing运行 `c22f258` 旧渲染器，逐字核对正文、seq、作者、引用、mentions、事件顺序和投递分区；没有运行第二组模型。

六个新wake按JSON表示合计减少756字节；包含历史重传的六份请求实际440,583字节，同输入恢复旧渲染时为441,960字节，差1,377字节。三次新投递的instance.created在数据库中仍完整保留两个内部字段。此探针只有同一顶层目标，线程/混合目标另由单测验证。

实现的分组条件比较渲染文本UTF-8字节，不是JSON编码字节；极短目标可能没有JSON字节收益，不能宣称所有目标都会节省请求字节。本样本各组均有正收益，但不提供token、缓存、真实质量或费用结论。私有原始轨迹、请求、数据库和SHA清单在 `~/.loom/reviews/2026-10-06-compact-wake-free/`。
