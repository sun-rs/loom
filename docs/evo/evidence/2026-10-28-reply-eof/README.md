# 共用回复 schema 与 Kimi EOF 修复

2026-10-28。本批修复前一批原生对照暴露的两处可重复缺陷，没有新增付费模型调用，也不补判原效率实验。

## 根因与改动

- 共用 `loom_reply` 的运行时校验要求新回复显式提供 `final`，但对外 JSON Schema 只要求 `body`。模型收到的结构契约允许服务端拒绝的调用。现用互斥分支表达新回复与修订：新回复必须有布尔 `final`；修订只允许正文与草稿 ID，不能覆盖原 final/序号。所有 CLI 共用此定义，不对 Codex 特判、不默认 final。
- Kimi 2.1.1 免费 ACP 探针只 initialize、session/new、EOF，没有 session/prompt。无 MCP 正常退出约 3.628 秒；带空工具 MCP 正常退出 6.299 秒，exit/close 时间一致，已超过原 5 秒期限。因此原限制可能误杀正常资源清理。等待改为有界 15 秒；仍要求真实退出状态，超时后 TERM 即使返回零也不能发布成功。
- Kimi 被取消请求在原 wire 中没有终态 usage，仍标未知。context/token-counting 不是计费凭证，不能用零补齐。延长退出等待不保证恢复这种缺失。

## 验证与限制

先运行失败测试，再修复：共用 schema/stdio 6 项、EOF/原生退出集成 9 项通过；根类型检查通过。JSON Schema 用 Ajv 真校验并与运行时 schema 对照，而不是仅检查源码字符串。真实 Codex app-server 免费读取该 MCP 定义成功（零 turn/start）；这只证明原生工具发现接受该 schema，不证明模型生成必定遵循。

Kimi 免费探针的时间是单次观测，不是时延分布或 15 秒内必然退出的承诺。集成测试覆盖晚到的正常/非零退出、超时后 TERM 返回零、忽略 TERM、取消以及缺工具终态。未运行无关全套测试，未改变 Web 构建。

旧 3.611 倍 Codex 输入开销及 Kimi 不完整对照保留；本批没有新的节省比例。后续如进行已批准模型的付费复验，必须固定重复组、保留失败费用和缺失计量，不能由此单独推断全部 CLI 成本通过。
