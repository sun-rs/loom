## 已接入的变化

| 表面 | 官方变化与 Loom 接线 |
| --- | --- |
| 外观／主题 | 有工作区时，浅色／深色／系统移入主题页顶部。外观保留主题入口、字号预览及显示偏好；设备明暗与 Kernel 工作区个人主题偏好保持各自所有者。 |
| 通知 | 个人浏览器通知与独立工作区通知分开。官方“服务器通知”是当前服务器／工作区静音，不是任意远程 Computer 的 AgentHost 开关。绑定现有带版本校验的静音偏好；不引入新的远程通知权限或改变本地／后台推送链路。 |
| 动态筛选 | 采用原生 DropdownMenu/PickerTriggerButton；全部／未读／提及／已置顶在菜单里，非全部状态显示可清除的浅蓝条件。清除后焦点回到筛选按钮，Escape 关闭；保留菜单原生 RadioItem 的关闭规则及原后端查询语义。 |
| Role 列表 | 官方计算机分组按钮、字体、间距、折叠样式；按 inventory 的精确 RuntimeOffer 绑定分组。未确认归属单独显示，不拆解不透明 ID，不默认归给本机。保留已删除分组和稳定 Role ID；目录探测不阻塞 Role 列表。折叠只保存设备呈现偏好。 |
| 计算机零实例 | 不创建空 ListRowGroup，因此没有多余边框／下划线；使用官方 `text-footnote text-foreground-hint` 简短说明。计数、实例／角色创建入口保留。 |
| 分栏 | 逐项结构比较确认与 1.21.34 注册表相同：普通侧栏240（200–400）、列表380（240–640）、thread400（min360）、detail400（min320）、sideCards360（min280）、文件树256（180–480）。保留拖动与已保存宽度；不因此改桌面或触屏断点。 |

生成入口为 `generate-refresh135.mjs`、`generate-appearance.mjs` 和 `generate-settings-sections.mjs`。前者同时校验来源摘要；自动测试直接比较此次保留控件的来源/生成 class 参数，避免只检查“导入了官方组件”。Loom SDK、修订围栏、未知结果恢复、草稿和路由保护保留。

## 空态审查

| 页面／区域 | 结果 |
| --- | --- |
| 聊天未选对话／不存在的目标 | 官方 EmptyState 图标、标题、说明与居中布局；正常空状态和不可访问状态区分。 |
| 频道／独立私聊／实例私密对话的空消息 | 同一正文分支复用“还没有消息／开始对话吧”组合；Side 继续保留自身只读／身份说明。 |
| 手机空频道列表 | 增加原生 EmptyState，保留原创建入口与 More/底栏层级；桌面窄侧栏仍用官方小字号说明，不重复摆放大型空态。置顶空组不错误显示“暂无频道”。 |
| Role 无配置／角色动态 | 主区域用官方组合；桌面列表用官方 SidebarSectionDescription 风格。只有已删除 Role 时默认保持空的活动角色页面，显式选择已删除项才打开其资料。读取失败保留错误状态，不伪装无记录。 |
| 记忆 | 无记忆与无匹配结果分开，用官方组合并在可用列表区域居中。错误／部分失败不显示成功空态。 |
| 任务 | 已使用官方 EmptyState；补齐“还没有任务”与筛选无匹配的标题和说明。 |
| 动态、搜索、已保存、消息列、附件评论 | 已委托官方 EmptyState 或相应生成组合；保留原场景，不改成一套新的自编布局。 |
| 运行时信息、归档列表、文件树内部小区域 | 这些是局部信息／列表，不是空白大页。保留官方轻量说明与原有读取／错误状态，不统一塞入大型图标。 |

Loom 的 Role/Memory/手机空频道文案是产品概念接线；不称其为官方逐字文案或整套 iOS App 原样移植。

## 验证

- 修改前确认所需行为测试失败；新增来源组合、归属分组、未知绑定、目录探测不阻塞、手机空频道和测试入口保护。
- 41项本批相关 source/UI-contract/完整性/单一运行时检查通过，Loom 类型检查与 `npm run build:web:workbench`。
- [桌面1440×1000／手机390×844触屏](browser.json)：主题及工作区静音保存/刷新、筛选菜单/条件清除/焦点、Role 分组折叠/刷新、暂停目录响应时先显示 Role，以及各空页。均无页面异常或水平溢出；鼠标与手机触控触发均检查。
- [分栏与设置导航](settings-sidebar.json)：拖动宽度、个人/工作区分组、草稿跨 tab、URL 重载/返回和键盘选择。旧脚本拖过最小值会触发官方侧栏折叠，现按原生最小值位置测量，保留完整的 min/max 断言。
- [运行时表单](role-form.json)：桌面／手机的模型、Fast、高级环境变量、默认仅保存配置、独立新增实例、失败保留已存 Role，以及删除/恢复后的冻结实例身份。计数检查实际实例行，不依赖文字间隔；手机使用官方 DialogSheetContent 标题关闭入口。
- [消息指标](message-metrics.json)：频道／私聊／消息列／任务 × 三档字号 × 两种宽度，共24个呈现采样。当前假 CLI 不实现真实工具宿主，其运行诊断不作为真实 CLI 验收；此项只验证已写入夹具消息的字体、头像与时间结构。
- 未运行付费 CLI 或完整后端测试；模拟视口不是实体 iOS/折叠屏验收。

调试中一次未注册的 browser slice 误落入旧默认流程；该次未通过，不计入验收。已修正入口：显式未知选项拒绝运行默认整套检查。旧脚本对外观入口、重复“通知”标题和手机设置底栏的过期断言也已同步，不为测试恢复旧 UI。

## 保留边界

本批不是“官网所有页面已永久一比一”的认证。公开原始源码仍落后，既有其他页面和移动端例外保持原来源记录。未因官网更新恢复多 Human、云账户/计费、第三方托管 MCP、Graph 或不具备后端能力的按钮。后续更新继续先抓取独立候选，再按来源、组合和状态逐项核对。
