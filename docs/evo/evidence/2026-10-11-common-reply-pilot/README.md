# 共用回复规则三组长任务对照（2026-10-11）

结论：本批完成计量，不接受候选为已验证的成本优化，不合入或部署。候选只是条件化共用回复说明，并非单家CLI提示策略；输入略低、组间方向反复，质量与模式限制不能消除。五家真实CLI的免费链路通过不等于五家付费效率通过。

## 质量和计量边界

- Kimi三个路径分别36/36功能、36/36作者自测通过，不能据自动检查宣称穷尽质量。
- Pi现行36/36功能通过；原生24/36，第一组12轮因元组/字典差异失败，但早期题目并未明确返回容器，不能笼统归为不遵循指令。候选29/36，第二组R6–12擅自按无关active字段跳过行，两项外部检查失败。三路径作者自测均36/36，表明自测不能替代外部质量验收。原判不改、不剔除失败组；不能主张同等质量节省。[题目歧义](return-shape.json)
- 主量以完整HTTP原流核算，响应ID、被动字节SHA、原生记录、封账总量交叉核对，所有216份逐轮产物快照哈希核验。Loom144次原Run/consumer交付确认独立于Task完成。Pi压缩响应总量与原生聚合一致，但4个Loom臂各有一个Kernel压缩gap；不伪造response ID填补，不称产品用量完整。[逐臂复核](raw-audit.json)、[压缩后续设计](compaction-design.json)
- 首八个封账臂有子代理独审；监看/审查代理额度耗尽后，lead直接从原流复核全部18臂，后续10臂不冒称另有独立代理审查。此前Kimi第二组现行独审收据复制了第一组slot标签，原文件保留；其源结果hash和用量对应第二组，lead已重新核实正确关联。[出处](provenance.json)
- 62,058冻结文件、99实际路径无漂移。控制器正常退出、所属进程及临时配置清理通过。完整资源封印不是操作系统级密封镜像。[校验](closure.json)

## 观察到的额外操作

Pi现行三组直接Worker调用0/3/0次；候选2/3/2次，另两次环境探索。包含读取、帮助与参数错误后修正；shell工具没有标错不代表Worker业务成功。候选并未保证消除多余检查。Kimi本批617个请求未匹配显式Worker/协议环境调用模式；这不是任意shell间接调用的不存在证明。

大量请求仍用于业务文件读写、测试及修错，正常历史随后续请求重传。总input比可以算术拆成请求数比乘平均每请求input比，但该恒等式不分离提示的间接影响，也不能将业务轨迹差异直接判作纯随机性或全部平台成本。[行为分类](trajectory-summary.json)、[算术分解](summary.json)
