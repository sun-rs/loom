# Native-final 连续复杂审查：固定三对验收

Owner 在收到剩余验收清单后要求「开始」。源码基线 `ead15510`；没有修改产品、重启正式服务或改变其数据。复用已冻结的 `restart-audit-12/v1` 源码审查任务（快照 `7afe141`），六个文件、十二阶段：分段阅读、跨层契约核对、回归计划与最终交接。它是复杂连续的只读审查，不是实际修改/执行交付，也不是多人协作。

## 计划与公平性

[固定计划](plan.json)记录模型、自动记忆策略、源码/题面哈希、native-final 模式和脚本哈希。Codex gpt-6-luna/low 与 Kimi kimi-code/k3-256k/low 各三对，每臂十二轮同一个原生 session，顺序 N/L、L/N、N/L。所有原生/产品启动沿已有自动记忆禁用与模型验证器。输入含缓存，不把 token 比率称账单比率。

每 CLI 上限为已观察500万输入、9万输出、70分钟；轮间检查，保留在途超额。遇到执行或计量失败停止该 CLI 批，不自动重跑或替换；语义失败保留且不以成功子集计算整体成本。两个 CLI 批并行，共享主机，时延只描述。Kimi 复用既有 role runner，在第三轮前重启隔离 daemon，原生 session 不变；不是无重启时延对照。

当前工具进程没有 `HERDR_ENV=1`。已阅读 `herdr --skill`，其规则禁止从非 Herdr 环境控制用户当前会话，故本批未执行真实 Herdr 协作对照；不以脚本转发冒充 Herdr。既有历史协作证据不更改，但不能作为新版本的同目标配对结果。

## 判定范围

- **执行/计量**：每轮真实输出、连续 session、源文件不变、Run与原生usage；最终逐 session 核对 Codex累计记录或Kimi每请求终态记录。没有缺失量按0补齐。
- **交付质量**：负责人按原有rubric核查各臂第6阶段状态矩阵、第9阶段缺陷分析及第12阶段最终备忘录。记录主要缺陷、保留安全检查的修复、回归方案与静态证据边界。这是定向、非盲审，不是每句全量审计或新独立模型评审。
- **指令遵循**：汉字数400–600单列。模型自称合规不是证据；长度失败不触发补跑。中间错误即使最终改正也保留。
- **倍率**：报告全部既定尝试的描述性总和比。技术质量不完全一致时不发布“同质量成本比”或统计等价结论，不把单对1.0作为目标。

## 结果

结构化完整统计见 [summary.json](summary.json)，质量观察见 [quality.json](quality.json)。两批按原计划全部完成，无替换样本：12个连续session、144轮（72轮Loom）。所有源文件哈希不变，12份原生记录与逐轮累计核账一致；Kimi60个Loom请求全部有终态usage。

### 质量结果不能被倍率盖过

- Codex原生第三组误记recheck两侧都已投影，否认真实的稳定目录误拒绝；最终仍按错误机制交接，主要诊断不通过。其费用未删除或补跑。
- Codex原生第二组、Loom第二组中间阶段均建议过忽略凭据目录字段，最终才转为保留集合检查；Loom第一组修复措辞仍需明确使用receipt期望值，不能直接拿中间回答写入代码。
- Kimi六份最终备忘录都找对主要缺陷和修复方向，但原生第一组此前误判普通queued可重启，未纠正；部分原生回答把后一个断言的报错文案错归到前一个断言。Loom第三组状态结果正确、NOT谓词解释措辞错误。不能宣称全文无误。
- 原始答复汉字数400–600的轮数：Codex原生4/36、Loom7/36；Kimi两臂各2/36。这里计整个答复的CJK汉字，不依赖模型自报，正文单独计数也不因此建立全通过。它是单列指令指标，不触发重跑或提示词优化。

因此技术质量等价没有完整建立，`equalQualityCostRatio=null`。上述输入比是全部既定样本的描述性算术，不是同质量成本承诺或完整发布门禁通过。定向审查仅覆盖第6/9/12阶段，不外推到每一句、多任务或多模型质量。

### 决定

这批支持停止针对Codex/Kimi普通最终回复路径继续追逐1.0：连续12轮下仍接近原生请求数，总输入增量约16.5%/6.1%，未复现旧工具路径的倍数膨胀。没有修改产品来迎合随机回答错误。仍缺新版本多人协作与真实Herdr同目标配对；单实例结果不能替代它，历史结果也不冒充本批结果。

本批总计6,892,855输入、79,732输出、242次生成；不是货币账单。已记录的81个进程PID全部不存在，见[清理证据](cleanup.json)。正式服务与用户数据未改动。
