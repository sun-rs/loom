- 实例操作：`AgentDetailPanel-CnHZV8Ck.js` 的 `Wa` 结构移植；响应CSS直接提取固定资源，删除旧重复规则。480px是资料容器门限。私聊、启停和调用方提供的重启沿用既有处理器。宽栏仍保留更多菜单供Fork/Side等Loom功能；频道头像入口没有重启回调，不伪造一个可用按钮。
- 计算机行：`MachineDetailPanel-DYB7F72N.js` 的普通/选择行均使用容器查询；简单在线/离线窄栏保留方块、隐藏文字，详细状态在窄栏移到副标题下方。模型与运行时由既有数据投影提供。正式页面只有简单在线状态，因此复杂状态分支只有源码检查，未制造运行工作。
- 任务：沿用官方 `sr-only / aria-live=polite / aria-atomic` 成功播报区域，挂在Loom确认成功回调；使用标题和Loom状态翻译。未移植整套新版键盘拖动、焦点恢复和不可移动列提示。不能以此宣称任务交互全部一致。
- 来源URL、hash和授权记录继续由 `page-audit/sources.json`、`published-2026-10-26/manifest.json` 管理。没有更改不可变官方原件。
