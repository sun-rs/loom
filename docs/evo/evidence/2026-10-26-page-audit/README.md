# 六组页面的 1.21.34 源码差异核对

日期 2026-10-26。范围：搜索、任务、Role、计算机、部分设置及频道菜单。取得并阅读固定 app-shell 引用的9个页面/组件资源，加已有 settings/app-shell，共11份；URL/原始SHA256见 sources.json，关键格式化语句见 source-excerpts.md。没有把抓取资源称为完整TypeScript源码，也没有把新翻译ID的数量当作功能数量。

这是源码组合与Loom绑定核对，不是所有分支、像素和真实操作的全覆盖验收。未修改产品、未重启、未运行模型。本轮13项现有定向源码检查通过；这些检查主要证明既有依赖/生成器未漂移，不证明以下新差异已经解决。
