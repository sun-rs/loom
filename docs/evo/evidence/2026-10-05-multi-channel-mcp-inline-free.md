## 实现范围

两臂继续使用相同源码材料、业务指令、十二题和真实同伴消息；原生不调用工具，产品每阶段只允许一个真实 MCP 最终回复。工具通信属于本次被测成本，不能从用量里扣除。生成数保留实际正整数记录，不要求恰好一次；工具后跟随生成也参与正式合同判定。

检查器只静态解析注册的实际 MCP 调用形态，不执行模型代码。它核对字面量 body、当前 seq、final、目标，以及对应 call id 的完整 published 回执，再关联当前 Run 的唯一真实帖子和 final marker。null submission_kind 自身不证明 MCP，CLI 回退不能冒充；调用前出现的回执、未知工具、额外业务工具、错误正文、旧事件或错误主体均拒绝。原生完整材料、后续不重发、逐字答案、原生记忆关闭、身份连续性、末轮检查及资源围栏保留。旧三个 profile 的实验身份回归保持不变。

## 免费真实链路及反例

使用 Codex 0.160.0、无账号配置的隔离 HOME/CODEX_HOME，仅连接本地假模型。正例 native 与 worker-mcp 各三条连续 session、每条十二轮，共 72 次实际 loopback HTTP、72 次合成生成。原生零工具；产品每轮恰好一个 MCP 调用。六个 session 首轮的新输入各有完整材料一次，后续没有重发完整材料；业务指令每请求一份，官方原生记忆关闭。

假服务只生成规范答案和工具调用，**MCP 发表、工具回执、平台 ACK 与中断均由真实 CLI/Host/Kernel 链路完成**，不是假服务伪造回执。独立审计六份 rollout 与只读 SQLite 快照，共 437 项检查，确认 36 份真实相关回执、36 唯一消息、36 ordinary final marker、36 completed Activation 与原消费者位置，以及 36 次终态中断。三个实例首轮对应同一材料消息与 Room seq。

两个定向负例独立验证停止与成本保留：

- 格式正确但正文错误：一次 HTTP、一次生成，实际发表后被新正文检查拒绝，下一阶段未启动。
- 额外工具加回复：两次 HTTP、两次生成，实际发表并自然结束后被工具检查拒绝；第二次生成及用量完整保留，没有因生成数大于一提前掩盖费用。

更早的免费尝试同样保留：三次原生侧遇到代理 503、磁盘 ENOSPC 和 list_turns 续接错误，未进入产品臂；两个早期负例 fixture 分别在正文前置检查和重复工具尝试处失败，不能冒充上面两项定向证明。两个安装路径的 CLI 二进制 SHA256 相同，不能归因为不同构建。磁盘空间恢复后才完成最终正反例。

[机器审计与归档哈希](2026-10-05-multi-channel-mcp-inline-free.json)提供完整范围。探针直接复用真实执行臂与逐轮检查器；新命令入口的预检、配置和摘要接线另由自动化测试覆盖，未执行付费入口。
