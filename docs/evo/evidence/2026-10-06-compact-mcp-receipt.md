# MCP 成功回执：最小模型投影

日期：2026-10-06。承接[上游源码研究](2026-10-06-upstream-context-design.md)及[长期成本归因](2026-10-06-long-cost-attribution.md)。本批仅改变成功回执的模型可见投影，不改变目标合同、工具参数、Kernel 业务响应、原生 session 或频道投递正文。

## 设计与所有者

`packages/protocol/src/worker-mcp-receipt.ts` 是唯一成功投影所有者。AgentHost 继续先验证完整 Worker HTTP 响应；协议投影再次解析完整 mutation schema，再核验 message.posted 类型。普通成功仅输出 `state: published`、`messageId`、`roomSeq`。内部事件、作者、频道、线程、activation IDs 不再随成功工具输出进入模型历史。数据库及完整服务响应仍保留这些字段；没有修改既有 session 历史。

例外信息保留：重复发表返回 `deduplicated: true`；非空 `unresolvedMentionHandles` 和 `replacedDraft` 原样返回。held、目标确认、确定错误、未知结果路径不变；未知写入不重发，原 Run/call 幂等及身份围栏不变。回执既不证明消费，也不完成 Task/Activation。

参考 Multica 的输出投影及 OpenHands 的记录/视图分离思想，全部为本地实现；无上游源码复制或结构移植。未新增状态、摘要模型、文件记忆或读取工具调用。

## 验证边界

先改测试并确认旧实现因多余字段失败，再改投影。集成测试以保留的 messageId/roomSeq 关联真实 Room 事件核验身份和频道；拒绝缺消费序号、真实 ACK、唯一消息/marker、幂等及旧 Run 撤销断言继续保留。不再展示的字段损坏仍必须在完整 schema 解析阶段拒绝。

历史证据验收兼容完整旧回执和严格的新回执，拒绝部分身份字段、未知字段、正常轮中的去重/草稿替换/未命中 @。作者、目标、事件、Run、消费窗口与 ACK 继续由真实持久事实验证，不以短回执代替。

本批不启动付费模型。字节下降只能证明输出精简，不能替代真实质量、计费 token、缓存效果或长期效率验收；P122 的既有失败结论保留。消息投递包装和常驻工具说明尚未改变，不能由这一刀宣称解决全部额外成本。

## 免费真实 CLI 链路

[脱敏审计](2026-10-06-compact-mcp-receipt.json)：已安装 Codex 0.160.0，隔离配置，原生自动记忆关闭，只有 localhost 假模型端点、无账号凭据及付费回退。三个真实原生 session 各两轮，共六次真实 HTTP 请求、六次 MCP 发表、六个唯一 Room 回复/marker 及同 consumer 的真实 ACK。三个续轮 HTTP 请求均实际携带首轮的精简回执；完整 MCP/代码执行包装和原调用身份未改变。

每份回执 JSON 实际 93 字节；对同一个持久事件重建旧普通成功表示为 316 字节。含外层包装的历史项实际 417 字节，对应重建 694 字节，差 277 字节。旧表示是反事实重建而非旧 binary 实跑；没有 token 分词或费用结论，也没有声称完整请求下降此比例。合成模型生成数与 usage 不用于效率判断。警告、held、去重及未知结果由独立单测覆盖，本链未注入这些情况。

私有原始证据：`~/.loom/reviews/2026-10-06-compact-receipt-free/`，包括六份请求、三份原生轨迹、数据库快照、源脚本及哈希清单。没有启动真实付费模型。
