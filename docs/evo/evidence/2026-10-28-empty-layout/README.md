## 官方规则与根因

官方 `EmptyState.tsx` 保留图标、标题、说明的原生组合；TasksPanel、SavedPanel、ThreadsInbox 的整页空态使用填满正文的居中布局。Sidebar.tsx 的 `SidebarSectionDescription` 明确用于分区内紧凑说明，不能和整页空态混为一类。MobileComputersPanel 和资料区块也有有意保留的顶部／段内空说明，不将所有提示统一挪到屏幕中心。

Loom 手机频道、Role 列表虽然复用了同一个 EmptyState，但用 `py-16` 代替正文高度，外层滚动区／右键触发表面没有建立剩余空间的布局链。桌面未选频道时还多了一行官方空正文没有的“聊天”标题，使提示下移。

修复限于 Loom 适配层：空列表时由现有 Frame／上下文菜单表面分配剩余高度，去掉固定留白；展开的已删除 Role 列表视为已有内容，正常滚动。桌面空正文隐藏多余标题，手机返回入口保留。官方组件、字体、尺寸、包与不可变源码不变；普通列表及行菜单保留原布局。规则已加入 `ui-contract.json`。
