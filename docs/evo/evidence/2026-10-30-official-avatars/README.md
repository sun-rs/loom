# 头像库切回完整官方版本

Owner要求头像系统的组织结构和图片使用Raft原版，取代此前539项宝可梦选择库。本批以已取得的完整Web1.21.40归档为唯一数据来源，不从旧16款自行扩画。

## 当前行为

- 官方9组×8款，共72个可选头像：机器人家族／小动物／太空／工位／食物／冒险／天气／植物／怪谈。图案、配色、顺序、分组与中文标题均来自归档原件；finch／mug两款保留头像不进入选择／随机池。
- 新Role从72款中随机选择，保留原有幂等后取样、持久修订与冻结实例规则。官方本身为有放回取样，头像可重复，不代表实例身份相同；独立的旧Agent均衡分配测试仍验证选未用项。
- 选择器使用既有官方框架、44px选择格和4／8列容器规则，移除宝可梦搜索、分页和额外随机按钮。新头像是原生8×8 SVG单图，不需要下载539张PNG。Role仍只保存preset key；没有在本批新增官方的自定义图片上传能力，不宣称整个官方资料编辑器所有能力一致。
- 既有宝可梦、Loom32×32、旧16款及用户图片不批量改写；539个PNG身份与资源继续支持旧Role／冻结实例／历史读取。只改变新建默认池与手动可选库，不删除用户已保存的头像信息。

## 来源与维护

`frontends/raft/loom/avatars/official.provenance.json`记录完整归档SHA、原始app-shell与zh-cn模块SHA。`generate-official-avatars.mjs`只解析字面量，不执行官网代码；从同一完整归档生成原始JSON、中文组名、Protocol身份键及来源记录。生成结果测试逐字节重算，不能手改。Protocol不持有颜色／图片，UI不负责身份分配。

这属于owner要求的图库数据／现有编辑入口切换，不是继续以不同Web版本拼页面，也不关闭[整版前端迁移](../../../design/full-official-frontend-baseline.zh-CN.md)的业务接线余项。完整官方归档和旧选定源码均未修改。
