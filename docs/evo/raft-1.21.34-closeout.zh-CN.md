# Raft Web 1.21.34 更新与收尾清单

核对日期：2026-10-26。结论：本次已识别的主题、列表布局、分栏和动态手势差异已接入；不能据此宣称全站最新版对齐。本记录是当前清单与历次证据的交叉审计，不是重新跑过所有页面的浏览器验收。

## 版本与依赖边界

- 官方组件包：`@botiverse/raft-ui`，从 0.10.5 升至 0.35.1；npm 别名仍为 `raft-ui`。
- 不可变选取源码：`db5e399f017d584e49597e3a28757645d6807893`（1.21.23-source.1），90 个选取文件在升级时校验一致。这不是完整官网应用。
- 新增兼容移植的生产资源基准：Web 1.21.34（97b97cfed9ae99d34ade2657b17e53c1a8d111ed）。旧版移植未因此全部升级。
- 当前产品部署：c70f542b；分批证据见文末。
- 本次尝试读取官网实时页面未成功，不能把 1.21.34 声称为此刻最新版本。已锁定资源是本清单的可复查基准。

## 已关闭的历史待办与保留限制

旧的各批 summary 是当时快照，不修改其历史结论。主题入口、窄屏工具条、动态独立折叠、滑动撤销、静音/取消关注接线现已完成，不能再按早期 remaining 重开。搜索列表折叠是先前误判，不是漏实现。

保留限制：关注关系无版本令牌，撤销无法区分另一客户端再次主动取消关注；静音撤销保守拒绝任何中间偏好修订；页面关闭时待提交操作为尽力发送，不是离线持久队列。不得为了视觉对齐削弱写入围栏。

## 收尾顺序与完成判据

1. 固定1.21.34，不在每轮换基准；优先逐项核对上表“本批未重核”的官方组合链与Loom绑定，记录具体差异，没有差异不改代码。
2. 补实际鼠标拖动与Side正式页面回归；隔离数据验证主题保存和动态次级操作，避免动用户现有偏好。
3. 真机验证滑动命中、纵向滚动/系统返回冲突、撤销及刷新后的状态。桌面模拟不能替代。
4. 每行标注“已验证／明确Loom差异／不支持且不显示／未验证”，并链接源码和证据；只有全部保留表面完成这个核对，才可宣布固定版本对齐。当前不得宣布。

本轮交叉审计查明的根因：包版本和页面资源版本混用，旧迁移计划完成被误当新版页面验收完成，后续切片证据没有汇总回当前页面清单。本文件补齐这层索引；它本身不提升任何未验证页面的验收状态。
