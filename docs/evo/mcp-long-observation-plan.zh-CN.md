# 默认 MCP：保留恢复成本的长期观察

此切片落实[验证设计审查](mcp-long-observation-review.zh-CN.md)中有明确证据的一项恢复规则。只修改验收工具，不修改产品工具参数、Kernel 或正式服务；P119 原始文件、失败裁决和旧 profile 均保留。没有新付费授权。

## 实现与界限

新入口为 [test-cli-multi-channel-mcp-observation.mjs](../../scripts/test-cli-multi-channel-mcp-observation.mjs)。同题同材料，双方官方原生记忆关闭、会话历史保留。native→worker-mcp，各三 session×十二轮，沿用旧方案输入/时间准入软上限和最多 36 产品 Run，不自动重试整批。两个 final-output 开关关闭。新实验身份：`45103559dfffa51d269112bcbffe41122d62947756626c0247b72c06e4918682`。

检查器只对下列完整证据继续准入下一阶段：此前调用是已注册的真实 loom_reply，body、当前 seq 和 final 正确，显式 threadId 被 Kernel 以精确的 scope forbidden 拒绝；每次真实结果与 call id 有序对应；同一 Run 随后产生唯一正确 published 回执、Room 消息、final marker 和消费者 ACK，全部用量完整。Kernel 的路由拒绝发生在发表前；检查器不合成 ACK、不代发、不替模型重试。

未知结果、非注册错误、额外工具、伪回执、重复发表、错误目标、身份/材料/记忆/用量缺口仍停止。错误最终答案仍停止，审查设计中的“错误答案后继续诊断”尚未实现；等价但无法识别的工具 wrapper 也仍会停止，属于证据提取限制。这是窄范围实现，不能称所有随机波动都已被容纳。

新摘要分开记录实际阶段数、已验证/未验证阶段、一次调用成功、恢复后成功及目标拒绝次数。未验证阶段不会从实际阶段分母消失；不把缺失当零。原有逐轮、首次与第 4/8/12 轮累计值继续计入全部输入、缓存、输出与生成。业务答案、合同裁决、观察是否完整各自独立。完整观察也不会自动标记预算达标。

模型思考和生成次数可以变化，不锁死为一次；已发生的恢复和跟随生成费用不可扣除。即使同题同模型，两臂思考路径、上下文和缓存也可能不同；实际成本差不自动等于纯平台协议开销。CLI 提供的思考 token 随原始用量保留，未提供时不能估计或人为归零。单 session 内的轮次相关，不能当独立重复样本来计算稳定性。新摘要始终输出 `stabilityVerdict: not-established`；一批结果只能是一次观察。后续如需稳定性研究，必须先冻结独立配对数量、执行顺序和预算并获批，不能运行到通过才停。

## 免费证据

新增测试先失败后实现通过，覆盖一次或多次注册拒绝后恢复、变化的生成次数、续轮不重发材料、累计费用、未知/错序/跨 call 回执、额外写入及旧证明不能冒充新证据。旧 profile 身份仍有回归保护。

P119 原始 rollout 仅离线重放：新观察器识别一次拒绝、最终送达，保留 2 次生成和 32304 输入。该重放不是新付费样本、不是 P119 改判，也不能把旧 native 分母拼入新实验。

免费真实 Codex 0.160.0 使用无账户配置的隔离 HOME/CODEX_HOME，只连接 loopback 假模型。两臂各三连续 session×十二轮，native 36 请求，产品 39 请求；预设产品第 1、13、36 阶段各一次非法目标，真实 MCP/Kernel 返回拒绝，随后真实发表并继续。材料仅在六条 session 首轮提供，后轮不重发，官方记忆关闭。假模型提供工具调用，不伪造 MCP 回执或数据库状态。

独立读取六份 rollout 和 SQLite 快照，471 项核对通过：36 Run、36 completed Activation 与准确消费者 ACK、36 唯一 final marker、39 durable usage 记录且无缺口；三次恢复成本都包含。见[脱敏审计与哈希](evidence/2026-10-06-mcp-observation-free.json)。这证明恢复观测链路可用，不证明真实模型正确率、思考分布或成本倍率。探针直接复用执行臂和检查器，付费入口未执行。

`npm run check` 全部通过（效率测试 402 项通过）；`npm run format:check`、本轮文档链接与 `git diff --check` 通过。没有部署或正式服务重启；工具参数收窄仍是后续产品工作。
