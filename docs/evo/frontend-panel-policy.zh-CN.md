# 官方面板宽度与响应式规则

2026-10-20 核对，锚点为已锁定 Raft v1.21.22。这里记录的是源码参数和 Loom 采用情况，不从截图猜尺寸。宽度单位是 CSS px；浏览器缩放/DPR与屏幕物理像素不能混为一谈。

| 面板                              | 默认 | 最小 |                      拖动最大 | 源码 / Loom 采用                                                        |
| --------------------------------- | ---: | ---: | ----------------------------: | ----------------------------------------------------------------------- |
| 聊天、Agent、计算机、设置左侧列表 |  240 |  180 |                           320 | 原生 `lib/panelBounds.ts` 的 `SIDEBAR_PANEL_BOUNDS`；四处直接导入       |
| 动态/搜索主详情结果列表（宽屏）   |  560 |  400 |                           720 | `MainLayout.tsx` 的实际 useResizablePanel 参数；Loom DiscoveryPage 同值 |
| 动态/搜索紧凑结果列表             |  320 |  320 |                           480 | 原生 `masterDetailPanelSizing.ts`，Loom直接导入；不是旧注释提到的240    |
| 记忆列表                          |  560 |  400 |                           720 | Loom扩展采用上述结果列表规则；紧凑时320/320/480                         |
| 消息列、Side                      |  400 |  360 | max(400, floor(窗口宽度×0.6)) | 原生 `panelBounds.ts`；拖动开始时重算最大值；Loom直接导入               |
| 实例资料侧栏                      |  380 |  300 |                           600 | 原生 `profile/ProfilePanel.tsx`；Loom InstanceInspector 同值            |

默认宽度仅在没有有效的本浏览器保存值时使用。Loom各页分别保存自己的宽度，调整Agent左栏不会改变聊天左栏。拖动上限与实际排版宽度不同：容器不足时，CSS可进一步限制面板实际宽度，不会为了恢复旧宽度撑破页面。

## 不是一个简单的“三列→两列→单列”窗口阈值

1. **普通列表/详情**：768px是桌面双栏边界；低于它按当前导航位置显示列表或详情，返回保留选择与草稿。导航栏本身不计作业务列。
2. **聊天＋消息列**：官方 `index.css` 中的 `thread-layout-container` 度量的是扣除左侧导航和列表后的可用正文宽度。仅当容器至少680px，而且窗口是横屏或宽度至少1280px时，正文与消息列并排；给正文至少320px。否则消息列覆盖正文，返回恢复原正文。竖屏平板不足1280px时也采用覆盖模式。
3. **实例资料侧栏**：窗口不足1024px时是覆盖层。达到1024px后还要检查内容容器：不足680px则折叠中间正文/资料，仅展示实例侧栏；足够时侧栏最大实际宽度不超过容器减320px。本批Agent资料/实例组合也直接采用这组官方CSS标记，不另写媒体查询。
4. **从消息列打开实例**：官方 `data-collapse-channel` / `data-collapse-thread` 标记决定临时折叠哪一列，关闭后恢复；并不是每次都追加第四列。

因此不应宣传“窗口小于某个固定值就永远只有一列”。例如本次实际浏览器横屏767×600隐藏左列表后，可用正文767px，仍能正文＋消息列并排；768×600反而显示桌面列表，使可用正文只有479px，消息列覆盖。这是原生组合规则的结果，本批没有自行平滑或更换断点。

## 本批验证

Agent左栏实际拖动检查240→320→180；实例侧栏默认380。左栏拖到320后，将窗口缩到1024，原生容器规则折叠中间Role资料，实例页占满剩余空间，没有三列挤压。消息列实际验证可用宽度679/680的边界、767/768桌面边界、1024横竖屏和1280竖屏。所有这些是隔离Core浏览器证据，不是物理iOS/Android验收。

源码：`frontends/raft/packages/web/src/lib/panelBounds.ts`、`components/layout/MainLayout.tsx`、`components/layout/masterDetailPanelSizing.ts`、`components/profile/ProfilePanel.tsx`、`components/agent/AgentWorkspace.tsx`、`index.css:794–974`。这些参数/组件是规则所有者；后续页面优先复用，不再逐页另造默认值或断点。
