# Claude Code「Code Mode」调研（2026-11-26）

来源：官方文档 https://code.claude.com/docs/en/code-mode ；本机 Claude Code 2.1.331 二进制字符串（未运行）；第三方单次实测（wmedia.es、Flavio Copes，汇总 https://agentspulse.github.io/tutorials/claude-code-code-mode/ ）。

- **是什么**：新增 `REPL` 工具，模型写一段 JavaScript（`` $`rg …` ``、`edit(...)` 等辅助函数）一次性串联/并行多个工具调用，中间结果不进上下文，只返回最终值。脚本在 Claude Code 进程内执行，**不在沙箱内**（仅 shell 命令遵守沙箱设置）；deny/ask 规则与 PreToolUse hook 仍逐调用生效；auto 模式分类器只审整段脚本，看不到运行时计算出的路径和值。
- **版本与开启**：v2.1.323 首发（实验性，默认关），后续 2.1.326–2.1.331 修复。开启 `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1`（shell 环境或用户 settings env；项目 settings 忽略），首次有确认弹窗；`0` 优先关闭。仅交互式 TUI、原生构建；`-p`/headless、SDK、IDE 面板、云会话、网关/代理、API key helper、ZDR/HIPAA 不可用。恢复会话需保持开启。本机 2.1.331 字符串中存在该开关。
- **收益证据**：Anthropic 未公布 Code Mode 的 token 或准确率数据。流传的 37% 来自 API「Programmatic Tool Calling」文章（43,588→27,297 token），不是这个功能。第三方单次测：输入 150k→95k（−37%，主要来自工具定义变小 24.6k→11.1k），请求数 4 vs 4，耗时 15s→37s；另一例 35s→15s。准确率提升无证据。
- **他家对应**：OpenCode v2 有 Code Mode（`execute` 工具）；Codex `features.code_mode.enabled`（开发中，第三方资料）；agy 未见。Cloudflare「Code Mode」（2025-09）是 MCP 工具转 TS API 的另一回事。
- **对 loom 的判断**：
  - 适合 TUI Claude **worker** 的扇出型工作（多文件搜索过滤、批量命令），可减少工具输出进上下文；不新增每条消息的请求，但"减少请求"不保证。
  - 对高级角色价值小（本就不该重度用工具）。
  - 约束：headless/OAR Claude 不可用；首次确认弹窗需纳入 PROMPT-STATE 识别或预先确认；脚本绕过沙箱，与 worker Seatbelt 隔离要求冲突，需评估；只能用启动级环境变量开启，不改用户全局 settings。
  - 建议：做一次受控 A/B（同卡同模型，开/关各 N 次），量 token、请求数、耗时、正确率，再决定是否给 worker 开。
