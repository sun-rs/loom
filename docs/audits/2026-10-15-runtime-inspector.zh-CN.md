## 数据与写入归属

- `role.list` 仍负责 Instance ID → Agent ID 映射；现有侧栏先验证当前成员属于频道或自己的私聊盒。
- 用量使用 `agent.run.usage.get`，逐次生成、完整性、输入／缓存／输出／推理、上下文和本轮压缩来自服务端。未知不补零；部分计数明确标注。原生压缩汇总独立列出，不与逐次生成相加。生成列表截断不改变服务端合计口径；不估计美元费用。
- 轨迹使用 `agent.trajectory.list`，每页 50 条，按精确 Room／Instance 过滤后以 serverSequence 排序。更早／最新使用不透明 cursor 替换一页，不全量拉取、不存入浏览器持久化。失败清空、重试；卸载取消请求并拒绝迟到响应。原始工具输入／输出保持普通转义文本，不转为可执行指令。
- 启停使用已有 `agent.manage/set_state`，控制 Room 的 RoomSession 和 WriteIntentSlot 提供因果基线及固定幂等键。未知结果只能核实原请求，禁止相反操作。后端仍负责 Human 权限；`agent.get.membershipRole` 是实例自身在控制 Room 的身份，不能当作浏览器用户权限。
- **停止实例**表示停用后续调度，并由既有 AgentHost 请求结束运行；响应成功不能当作进程已退出。**启用实例**恢复调度／待办处理，保留实例与当前 session，不等于新建会话或立即产生模型回答。真实终止情况仍看运行事件。未修改后台调度、上下文、模型或数据协议。

## 验证与保留边界

先有失败测试再实现：动态组件／加载规则，轨迹隔离与分页，未知／部分用量和启停未知结果保持。临时真实 Core 的浏览器测试覆盖桌面 1440×1000、手机 390×844，DPR 1；启停写真实临时状态，诊断轨迹／用量的 HTTP 展示夹具明确标注。失去停止响应后核实原键；取消不写；实例身份与配置修订保持。

追加故障测试复现了未决停止操作遇到聊天同步失败时，旧父级会卸载详情、丢失核实入口。现在仅在存在未决写入时保留所选身份与写入组件；不会保留失败的诊断数据，也不扩大读取权限。核实完成后恢复普通成员失效关闭规则。失败测试及修复后结果均保留。

正式页面只读比对已有真实运行与 API；不为验收开启用户实例或调用付费模型。后台原有停止／终止围栏由完整确定性检查覆盖，本批不声称新增真实 CLI 中途停止验收或成本结论。

仍未接入：其他详情标签、轨迹跨页合并排序、费用估算、全局用量页、profile URL 深链；部分原生诊断事件名称保持原值。用量与轨迹目前通过消息头像的动态侧栏进入；Agent 实例列表只增加启停，不增加平行详情页。正式结果与部署见[本批证据](../evo/evidence/2026-10-15-runtime-inspector/summary.json)。
