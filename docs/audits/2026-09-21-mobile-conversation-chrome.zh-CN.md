# 移动端会话标题栏、搜索身份与点击反馈

## 所有权和来源

沿用 [共享导航合同](../product/shared-conversation-navigation.zh-CN.md) 的单页返回、分栏关闭规则，不增加 PWA 独立导航状态。`ChannelHeader` 和 `AgentUnavailablePanel` 负责标题栏呈现；搜索目的地身份归现有 `principalId`，不是显示名称或头像。

上游版本/哈希及许可证来源沿用上述合同和 [大页选择审计](2026-09-20-surface-selection-parity.zh-CN.md)。本批是 RAH 接线修复：已有 Raft 粉色 token 和共享 PanelHeader 原语的使用，不是复制新上游源码。Multica 的路由不是此项目的跨大页导航 owner，不引入其状态。

## 已定位并实现

- 频道/私聊同时出现返回和 X：关闭回调在移动端也存在，X 却没有使用桌面可见性类。现只在分栏宽度显示 X；移动端保留原返回回调。
- 普通搜索中的同身份重复：既有私聊目的地和人员目录各生成一个入口。现在按 `principalId` 合并，并使结果计数与可见条目一致。相同名字、相同头像、不同身份不合并；不删除业务记录。
- 不可用 Agent：此前是自定义标题图标和只含 X 的标题栏。现在复用 PanelHeaderIcon/Action，移动端返回、桌面关闭；返回标签区分成员列表、成员管理和聊天。
- 移动聊天列表按下反馈：保留返回后无持久选中，按下使用已有粉色；规则覆盖桌面 hover 的白底，取消/松开自然清除。没有人为延迟导航。
