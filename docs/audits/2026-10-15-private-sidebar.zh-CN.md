# 实例私聊侧栏对齐

源为 [raft-source a98ae003](https://github.com/botiverse/raft-source/tree/a98ae003246a0360872a77d76dec2fccd0347ef7)，FSL-1.1-ALv2，沿用 owner 授权。官方 `packages/**` 未修改，出处登记在 `frontends/raft/adoption.json`。这是本地数据适配与结构移植，不是整份 Sidebar 的逐字复用。

## 规则与接线

先读取官方 `Sidebar.tsx` 的 `sidebarItemClass`、`DmRow`、私聊分组、隐藏／恢复、未读重新显示和右键菜单，再接入现有 Loom 能力。单一持久 owner 为 Kernel sidebar preferences；私聊键为 `peer:instanceId`，不是 Room ID。目录与正文继续通过现有 SDK 和 client-core 获取，不创建第二份消息存储。

| 官方触发与组件                  | 本地接线及状态                                                                                                                                                                                                                     |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DM 行头像、名称、选中、未读徽标 | `PrivateBoxRow` 结构移植 DmRow，直接使用原生 AvatarSlot／SidebarItem／SidebarItemCount；字号、间距、颜色、hover 与 selected 参数不改；置顶行允许换行，普通行截断。实例名称来自私聊 Room，未读来自 activity summary。               |
| 私聊分组、计数、折叠及排序箭头  | 独立 `dmSortMode`／`dmOrder`；沿用原生折叠未读 AttentionDot。官方此分组无加号，本地也不添加。空目录不显示此分组。                                                                                                                  |
| 行右键／键盘／长按              | 复用既有菜单 primitive；移动分组、已读／未读、置顶／取消置顶、关闭会话。不添加频道专有静音和归档。Escape、外部点击与焦点返回沿用 primitive。                                                                                       |
| 拖动                            | 复用现有 dnd-kit 指针／触摸／键盘传感器；私聊不能拖入默认频道分组，频道不能拖入默认私聊分组；置顶和自定义分组接受两种会话。非手动排序拒绝行重排。                                                                                  |
| 关闭／重新打开                  | 现有版本化 sidebar.patch 写 hiddenDms，不删除消息、不停止实例。只有确认成功才退出当前私聊；异步结果不覆盖后来导航。未知结果保留原意图，核实使用同一个请求。成员页或 Agent 页的既有私聊入口重新打开同一 box，并由 Kernel 恢复可见。 |
| 隐藏私聊有新未读                | 依官方规则临时重新显示，保留已保存的隐藏偏好，不伪造已读。                                                                                                                                                                         |
| 实例移除                        | 保留私聊历史入口和既有只读正文／禁用发送规则。                                                                                                                                                                                     |

加载、错误与重试仍由原有侧栏读取与 WriteIntentSlot 管理；迟到读取按 request ticket 丢弃。无未知写时才允许关闭，关闭未确认不提前隐藏或丢弃草稿。未接入的在线状态和草稿徽标不做假显示。

## 验证与边界

先红后绿复现：原页面没有私聊列表项；私聊被误归入频道排序；关闭后有未读未恢复显示。单位测试覆盖 peer 身份、独立排序、隐藏与新未读、拖动目标限制；浏览器覆盖双尺寸下置顶持久化、关闭保留历史、重新打开同一 box、未知关闭原请求核实。最终检查和部署证据见 [本批记录](../evo/evidence/2026-10-15-private-sidebar/summary.json)。

不新增后端接口，不改调度、模型上下文、token 统计或实例生命周期。Side 不进入普通实例私聊列表。跨窗口新建私聊的目录即时刷新、可见窗口自动已读、在线／草稿徽标、完整搜索页组合与实例 inspector／Fork／Side、任务／设置仍未收口；本批不宣称完整产品前端完成。

全仓回归另发现一个测试时序缺陷：Claude 假进程的结束记录与 Host 诊断走不同通道，立即检查诊断可能抢先。保留中断与诊断断言，仅补有界等待；无运行时实现改动。首次失败与复验分开记录，不宣称首次全绿。
