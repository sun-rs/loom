## 所有者与边界

通知配置由既有 SDK `push.configuration` 读取；页面只读，不触发权限申请或任何推送写入。当前 HTTP 局域网／Tailscale 地址不满足浏览器安全上下文要求，且前端没有完成订阅和通知点击回跳。此页完成的是状态展示，不是 Web Push 端到端验收；站内动态及未读功能独立保留。

动态的 `activity-position.ts` 单独拥有 sessionStorage 中的一条展示记录，仅含 Human／workspace／filter 范围字符串、depth、top。保留现有内存回退，存储不可用不阻塞页面；上限沿用10页／200行。恢复时由现有 feed 使用新游标重新读取授权数据，旧游标、消息正文、业务状态均不保存。切换筛选或身份回到起点；只保留最后一个范围，不生成多份业务缓存。位置是像素位置，列表内容变化可能使对应卡片变化；不宣称消息锚点永久稳定。
