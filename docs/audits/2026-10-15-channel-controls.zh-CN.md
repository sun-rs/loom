# 频道急停／恢复与最小运行设置

本批为官方前端接线，不扩建冻结后端。来源为 [Raft 官方源码](https://github.com/botiverse/raft-source/tree/a98ae003246a0360872a77d76dec2fccd0347ef7)，版本 `a98ae003246a0360872a77d76dec2fccd0347ef7`，FSL-1.1-ALv2，沿用 Owner 授权和现有 notices。冻结上游文件未修改。

## 采用与边界

| 入口             | 官方组合                                                                                                                                            | 本地接线                                                                                                      |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 聊天顶部更多操作 | `channel/ChannelOverflowMenu.tsx` → `ui/OverflowSheet.tsx`，原生 icon-sm trigger、右侧 34rem 上限 drawer、普通操作行                                | 保留频道名称与急停入口；未移植未接通的其他设置项，不用另造菜单尺寸                                            |
| 急停与恢复       | `message/SOSDialog.tsx` → `ui/DialogCard.tsx` → `Modal.tsx`，max-w-sm、p-6、原生按钮、四行 Textarea、Banner                                         | 结构移植，替换 API 和状态机；显示后端 stopping／stopped；需要终止证明才称已停止；必填恢复指引，保持会话和历史 |
| 设置             | `settings/SettingsPanel.tsx` 的 Panel／PanelHeader／px-5 py-4 内容层；`UsageDataSettings.tsx` 的 Card；原生 SectionHeader／FormField／Input／Button | 仅一个运行设置分区，开放本机并发上限；其他已列参数只读。没有多账户、计费、第三方 MCP 或预热开关               |

这是结构移植与原生组件直接复用，不是整个官方页面逐字节复用。设置只接单分区，不制造空的子导航；当前生效值折叠区为本地数据展示。

## 单一状态归属

- `room.execution.read` 读取当前未恢复的急停；恢复后 operation 为 null。不从最近聊天、工具日志或局部事件窗口猜测状态。
- `room.sos.stop/resume` 继续由 Kernel 所有。RoomSession 提供因果基线；WriteIntentSlot 冻结 Room、指引、基线和幂等键，失去响应后只核实原请求。私聊和归档频道不展示此操作。
- `runtime.settings.read/update` 仍由 daemon 的运行设置所有者处理。仅提交 `expectedRevision` 和 `maxConcurrentRuns`，不顺带回写其他参数。轮询不会覆盖编辑中的草稿；较旧读响应不得覆盖已经确认的新修订。修订冲突保留草稿并要求重新读取。
- 设置更新没有幂等结果查询，不能把相同生效值当作原请求成功的证明。响应未知时禁止继续保存，明确提供“放弃核实并重新读取”；不自动重发，不宣称原请求失败或成功。
- 未决操作阻止站内导航和浏览器站内后退卸载原页面；硬刷新／跨文档离开仍通过既有 beforeunload 提醒，由用户决定。未添加第二个业务队列或持久化副本。

## 验证与剩余范围

测试先复现缺少入口、未知结果丢失以及站内后退卸载写入所有者，再实现接线。临时真实 Core 在桌面 1440×1000 和手机 390×844、DPR 1 覆盖取消无写入、急停丢失响应后的原请求核实、刷新保持停止、指引恢复、设置保存、修订冲突保留草稿、未知结果放弃追认后读取以及站内后退保护。假 CLI 只用于临时发现，不是实际模型执行。

正式服务验收只读展示和 API 对账，不急停用户频道、不改用户并发、不运行付费模型。完整检查、页面证据及部署结果记录于[本批证据](../evo/evidence/2026-10-15-channel-controls/summary.json)。

本批不包含单 Activation 阻塞放弃／held 恢复入口；它与频道急停不同，仍在 console。记忆、任务、Fork／Side、附件与线程也未因此完成。高级运行保护参数保留 console，不据此删除临时控制台。本批未改变调度／prompt／上下文，不形成新的成本或真实 CLI 停止验收结论。
