# 系统记忆管理页

来源：`https://github.com/botiverse/raft-source`，修订 `a98ae003246a0360872a77d76dec2fccd0347ef7`，FSL-1.1-ALv2；原 LICENSE 与源码保留，`raft-ui` 0.5.64。

官方 `components/agent/AgentWorkspace.tsx` 是实例文件浏览，不是 Loom 频道记忆数据库，未伪称整页直接复制。此页是本地业务组合：沿用现有官方 `MainLayout` 主从分栏结构、`Sidebar` 包装、`PanelHeader`、`PanelResizeHandle`、`useResizablePanel` 与 `SIDEBAR_PANEL_BOUNDS`；列表用 `SidebarItem`，编辑用官方 `FormField`、raft-ui Input/Textarea/Dialog/Button/DropdownMenu。没有修改官方源码或新增主题样式。

## 能力和边界

- 系统导航的“记忆”：左侧全频道索引、频道和状态过滤、搜索；右侧按需读取正文。移动端列表／详情逐级返回，桌面原生分隔线可调整宽度。
- 列表不读正文；每频道最多 200 条索引，全文搜索最多 50 条有效记忆，API 没有分页游标。截断与部分频道失败明确显示，不冒充完整结果；搜索时状态固定有效，不能用有效搜索伪称搜索失效正文。
- 置顶、失效／恢复、删除复用既有 Human API。编辑简介／正文是本轮 owner 明确批准的窄扩展：Protocol schema → SDK → ApplicationService → Kernel `humanUpdate`，沿用既有事务、权限、修订、幂等、事件与 Human 来源记录；不改变 Worker、Side、模型投递或频道隔离。
- 未知写入保持同一 WriteIntentSlot、参数、修订和幂等键；路由切换被阻止，提供核实或放弃。修订冲突不自动覆盖或另键重试，编辑草稿保留供用户比较。
- 全局管理入口不赋予实例跨频道读取权限。全局 Human 新建、跨频道搬移、无界历史、失效记忆全文搜索、修订历史 UI 与频道/成员记忆权限 UI 未包含；控制台保留。

## 验证

先增加失败测试，再实现 Human 编辑与传输。定向 Kernel/API/SDK 测试覆盖修订、来源、非管理员拒绝、伪造来源拒绝、失效不可编辑、幂等重放与既有记忆边界。浏览器 fixture 使用真实 Kernel/API/Gateway、临时数据库与 fake Worker，不启动 CLI 或模型；1440×1000 和 390×844、DPR1 验证列表、正文搜索、编辑、置顶、失效／恢复、删除，以及编辑和删除丢失响应后的精确核实。真实部署只读检查不写用户记忆。最终结果与部署在同名 evidence summary 中记录。
