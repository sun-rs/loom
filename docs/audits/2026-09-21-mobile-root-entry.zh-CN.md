# 移动端大页入口默认列表

用户2026-09-21确认：点击移动端/PWA底部大页入口，应先显示列表，而非自动打开上次详情。
这修正[此前选择记忆合同](2026-09-20-surface-selection-parity.zh-CN.md)中成员自动选择第一个Agent并显示移动详情的行为。
Raft版本及来源仍沿用该合同；这是新的用户明确产品决定，不声称Raft所有入口都采用此规则。
沿用前批Raft/Multica对照，未引入新上游代码。

## 入口与宽度分开

- 移动端成员大页入口：清除当前详情路由，不恢复桌面的最后详情URL；无明确身份时不自动选第一个Agent。
- 列表点击Agent/Human/关系图、明确详情链接：仍进入对应详情。
- 当前桌面详情缩窄：保留已打开内容，不因宽度变化返回列表。
- 移动端设置入口：去除旧settingsSection，显示分类列表；明确设置链接仍有效。
- Computer已有移动端列表初始状态，本次检查保持；首页与任务继续其既有根入口语义。

App只在明确移动端入口动作选择根路由。AgentDirectoryPane仍负责本页详情呈现；
SettingsSurface的indexRequest仅通知同页根入口，不保存业务或导航副本。
浏览器/PWA采用同一宽度判定，不加入平台分支。

## 性能范围

Agent/Computer及文件树已在[前批](2026-09-21-directory-resize-isolation.zh-CN.md)隔离宽度更新。
此次把设置页加入同一测量脚本：40次1600→1444px连续缩放，设置内容0次重渲染，ScriptDuration约0.7ms。
没有证据要求再重写设置布局；保持原实现。跨断点的必要更新不视为性能错误。
