Raft v1.17.3 的 `index-CyTLLjYb.js` 与 `index-DLWPJCiz.css`，URL／精确 SHA 见[上一批来源记录](2026-09-21-raft-width-render.zh-CN.md)。当前 pretty 主包：`$F` 170874 行为 `mb-1 mt-3 ... h-6 ... px-2`；`cx` 171104 行为 `mb-1 ... gap-1.5 px-2 py-2 ... md:py-1`；`Ve` 172299 行为 `px-2 py-3`；计算机组标题 174340 附近为 `gap-1 px-2 mt-1.5 mb-0.5 text-[10px] font-mono`。

在隔离 Chromium 中载入该原始 CSS，按源码普通 block 成员结构测得下表，含相邻外边距折叠；不是截图像素推测，也不是当前线上完整成员页双边验收。只移植参数与可见几何，未复制上游 bundle 或增加依赖。Multica 的列表并非这套 Raft 分组模型；沿用既有成员呈现 owner，不另建组件。

手机聊天此前用户确认的 32px 行高、2px 行间距及 8px 分组上距有意保留；本次不把桌面间距强加到手机。成员行高与移动端既有密度保持，采用同一已核实的图文与分组间距。
