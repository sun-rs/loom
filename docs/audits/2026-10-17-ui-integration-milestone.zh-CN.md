# 官方前端主链路接线里程碑

## 范围

本次只收口官方前端与既有本机后端之间的纵向路径，不新增后端能力，不恢复旧复刻UI，不改模型提示词/上下文/调度策略。里程碑标签计划为 `milestone-evo-official-ui-integration-2026-10-17`；最终部署和推送以[证据](../evo/evidence/2026-10-17-ui-integration-milestone/summary.json)为准。

## 发现并修复

1. 私聊发送响应丢失后，手机返回聊天列表被错误禁止。表情/任务组件共享频道的 WriteIntentSlot，却无差别登记离页围栏；Map 同时让多个组件注册互相覆盖/注销。改为每个组件独立注册引用，表情只持有 message-save/message-reaction，频道任务只持有 task-create。消息发送仍由 ChannelApp 的持久桥保存，真正的消息列/Side/记忆等路由局部操作仍禁止丢失未决写入。新测试验证作用域与注销独立性，原浏览器失败场景保留后通过。
2. 搜索／动态切换缺少 room 参数时，频道回落到默认选择，未发送草稿丢失。保留最后有效频道的展示选择，使现有 Channel/bridge 在无新目标的大页切换中保持挂载；显式新目标和无权限目标仍优先处理，不扩大读取权限。已有草稿保留断言先失败，再通过；未新建第二份草稿或业务缓存。
3. 手机首页打开搜索／动态继承旧 room，导致大页误进入结果详情并隐藏列表。进入发现大页时清除 room/detail 参数，聊天选择单独保持挂载；新移动检查必须看到实际搜索输入框，不能只以底栏隐藏判定成功。
4. 旧管理与导航测试还在找移动底栏的“频道”和独立“搜索”。消息列测试仍使用旧英文关注文案。按已采用官方首页／聊天列表入口和中文文案修正定位，不为适配旧测试恢复过时界面。新组合夹具发送前明确禁用实例，消除假发现CLI被意外当执行器启动的噪声；没有真实模型调用。组合私聊用例最后会移除首个实例；后续提及用例错用已移除成员，且列表同名文字让旧定位提前成功。现改用仍在频道内的另一成员、限定官方 autocomplete 候选并按候选索引选择，保留不发送及精确成员断言。早先只归因为候选查询的判断不完整，失败记录保留。

## 保留边界

- 这不是“全部官方功能照搬完成”，也不是新增五CLI真实质量或成本验收。后端冻结与历史付费结果保持原判，见[后端冻结证据](../evo/evidence/2026-10-14-backend-freeze/summary.json)。
- Web Push订阅、交付与点击回跳尚未接通；当前HTTP LAN/Tailscale受浏览器安全上下文限制。通知页目前只读能力状态。
- iPhone/iPad真机、iOS键盘/PWA仍需设备验收，模拟尺寸不等同真机。
- 远程计算机、云账户、分享、音视频及未支持的官方入口不属于本次本机MVP。
- 官方原始源码版本/许可沿用 `frontends/raft/adoption.json`，本批不改官方文件。交互变化只在Loom接线层；没有改写原生尺寸、字体或配色。
