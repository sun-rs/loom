## 批次 4 的改动边界

第一步：同值 token 替换（`--space-1/1-5/2/2-5/3`、`--control-9: 36px`、`--control-5: 20px`、`--icon-2-5: 10px`、`--bw-1: 1px`）只替换本文件列出的规则；门禁基线 diff 为空。

第二步：有双边证据的差异，逐条独立：

1. 行高 52：去掉 `.rah-message-avatar-trigger` 的 `margin: 2px 0` 与 `.msg-head` 的 `margin-bottom: 2px`。门禁断言首行高 52。
2. `formatMessageTime` 结构移植：新建共享格式化函数（今天 / 昨天 / 同年 / 跨年，locale 与小时制沿用 RAH 现有日期设置），消息时间、线程预览时间、悬浮时间统一使用；`昨天` 文案走现有 i18n。单测覆盖四段。
3. 作者行角色/描述槽：Human 显示 Room 角色标签（现有 `MembershipRole` 投影，"所有者"/"管理员"/"成员"），Agent 显示定义描述；样式 12/16 mono black/40 truncate。不新增权限概念。
4. 分组与紧凑行：移植 `eat()` 判定（同发送者、同日、非 system、非高亮），紧凑行去头像去作者行，左侧 36px 占位内含 hover 显示的 10px 等宽时间；`showDayDivider` 由 `dayKey` 变化驱动，与现有日期分隔逻辑合并而不是并存。这是本批最大项，先写判定函数的单测，再接渲染。
5. 任务徽标补 `@认领者`（认领者名来自现有 Task 投影），保持 `data-task-status` 与状态色。
6. 线程预览头像边框 2px → 1px（`--bw-1`）。

## 自动检查要求

沿用批次 2 的六条。夹具需覆盖：首行、紧凑行、system 行、含任务徽标与线程预览的行、日期分隔；状态 base / hover / focus-visible；视口 1440×900 与 390×844。`formatMessageTime` 与分组判定以单测固定，不靠浏览器门禁。
