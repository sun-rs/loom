## Addendum (Super) — item 0, do first: tests must never pop real macOS notifications

Fix: tests and isolated live checks must stub/disable the desktop route (e.g. `LOOM_DESKTOP_NOTIFY=0` honoured by loomd, set by the test harness and all exp-relay runners); add an assertion that no test invokes osascript.
