# HIST-0 结果

## 交付

- `index.register`、`index.update`、`index.query` 使用 Node 内置 SQLite。批量导入在单个写事务内提交，`query` 通过只读连接执行。索引支持 `super`、`leader`、`auditor`、`worker`，保留 `transcriptPath`、`baseCommit`、`runtimeId` 和 `cli`，`account` 为 `null` 占位。EVID-0 可用 `query({ addr })` 取基线与记录指针，HANDOVER-0 可用 `query({ project, role })` 获取会话及 `parent`。
- 导入器读取 `workers.md`、relay 事件和 OAR 元数据。源记录缺失的身份字段保留为空，完轮事件不会登记为会话退出。导入重复执行会补齐空字段，并保留已登记的会话绑定。
- `bin/loom` 提供 `hist`、`state`、`ls`。续作、换班或压缩后新开的会话通过 `parent` 指向前序。`hist <addr>` 可沿同项目、同角色的链查看前序，worker 链同时匹配任务。`hist --role leader --project P --since <时间|turn>` 使用含下界的 ISO 时间或轮次游标跨会话查询。L2 默认展开一轮，可用 `--since 'turn:ADDR#N' --level L2` 定点查询。
- 活动 TUI 通过 `hc read --json` 和适配器 `screen.classify` 观测。活动无头状态返回 `unsupported`，原生 Codex／agy 无头历史已接通。Codex 的两项可移植性修复均在 `adapter.test.mjs` 内，按目录 realpath 验证 `--cd`、信任设置和原生记录定位。

接口、索引路径和命令示例见 [会话索引使用说明](../../index/README.md)。

## 实验验收

从两轮 H0／H1 的 `workers.md` 和 relay 事件共导入 22 条登记，再按实验清单补齐会话指针。两轮共 42 个会话，包括 10 个 Orca 无头 worker。读取范围为两轮清单明确列出的测试记录，并校验实验 cwd、原生文件名和会话 ID。逐一调用 `loom hist --json`，用原生记录核对轮数、工具计数、可识别的首条非零退出码及回复首段前缀。`super` 未出现在这两轮清单，索引登记由单测覆盖。[重放脚本](verify-experiments.mjs)
