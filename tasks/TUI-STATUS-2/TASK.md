# TUI-STATUS-2 — make the Status tab look like a product (pilot-2 goal 6 candidate)

User 2026-11-26: the Status tab is "非常不正式". Design basis: docs/research/2026-11-26-status-tui.md (Solars ratatui design, library survey, mock).
- Keep the zero-framework renderer (`cli/status-tui.mjs`); add one width dependency (string-width or get-east-asian-width) and a ~200-line layout module (box/columns/table) that pads/truncates by display width with `…` and wraps on word boundaries; vendor pi-tui's MIT truncate/wrap helpers with attribution; truecolor/256 with `NO_COLOR` fallback; redraw only changed lines; `--once` stays plain.
- Layout (two columns ≥100 cols, stacked below): framed header (project, online, loomd release, time) and page tabs (Board, Workers, Gates, Notices, Cost); Leader/Auditor cards (cli·model, state badge, context %, last activity, short id); Delivery strip with badges and oldest age; Workers table (task, wave, state, cli, short addr, age); Gates/verdicts; Super notices one line each; cost pyramid as meter bars; Accounts block (placeholder until pilot-cell's `loom accounts` lands, then wire it); Release line; footer key bar (↑↓ select, Enter detail, h hist, g grep, m mem, r, q, ? help). Colors from the Solars palette. IDs as first 8 chars; Enter opens a detail overlay with full Herdr tab id, session UUID, paths, verdict text.
- Noise: do not raise "pyramid inverted" or "tool output share" notices until there is a minimum sample (e.g. ≥ N model calls per role in the window, and workers have started); show them as neutral "warming up" instead.
- Tests: snapshot renders at 80/100/140 columns with CJK and emoji content, NO_COLOR, narrow stacking, truncation; hot-upgrade reconnect still works.
