# PILOT-FIX-3 结果

- agy 的草稿读回按 xterm `isWrapped` 拼接物理续行，再对观察到的草稿和原始投递统一折叠空白。编辑框须以本次 `[loom:<id>]` 开头，规范化后的完整内容须通过 SHA-256 比对。
- 实测 agy 1.5.16 会把一次粘入的 40 行折叠为占位符，因此 Loom 按原始换行边界分段粘贴。每段通过验证后才追加下一段，分段保留原文。整条草稿验证完成后只按一次 Enter，仍以原生回执确认投递。Orca 的 agy 配置在多行粘贴后额外等待，并用原生轮次事件确认生效，Loom 另加了画面证据。
- agy 的 `↑ N more lines` 表明头部已滚出编辑框。Loom 保留本次已验证的头部标记，用上一段的尾部与当前可见开头重叠计数，从实际读回累积规范化总长度，并核对当前尾段。隐藏部分仍属于同一次粘贴的依据是其间没有人工输入、终端尺寸变化、缓冲区切换或新原生轮次。缺少已验证头部、有效重叠或完整长度证据时保留 `draft-held`。
