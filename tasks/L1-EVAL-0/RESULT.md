# L1-EVAL-0 结果

已完成 [评审样本包](PACK.md)。主样本包括实验第二轮的 3 个 Codex worker、3 个 agy worker，以及 3 个 Claude TUI 会话。Claude 两份原生记录各含一次用户中断，其中一份保留了同一会话内的五轮交互，包括中断、恢复和后续输入。另附一份 [OAR 无头会话](oar-headless-codex.md) 供对照。

每份样本列出逐轮原生最终回复、含事实行的 L1、经过筛选的 L2、逐轮 `--diff` 回执及可取得的证据。大小按 UTF-8 字节计，token 以字节数除以 4 后向上取整。留存的 Git 引用只有初始提交，所选轮次缺少结束提交，`--diff` 回执均为 `missing-boundary`。LOOM-CLI-0 样本保留了波次的两张 Loom 证据卡，Orca 样本附有按派工 ID 核对的完成回执。

[只读样本脚本](read-sample.mjs) 对未入索引的记录直接调用 Loom 的历史读取器和原生适配器。每份样本的 L1 旁附有 [活动摘要原型](activity-digest.mjs)，从工具记录提取读写路径、可确认的行数变化、命令退出码、测试计数、轮次状态和最终回复首行。OAR 示例的归档只留存轮次事件，工具详情取自同一会话的原生 transcript。另用有工具事件的结构化输入验证了 OAR 平铺事件、原始帧和 Voyage 三种格式。

样本包含 6 个评审问题和 4 个已复现的提取问题。全仓 `node --test` 通过 231 项。10 份样本均已逐份重新生成并比对，索引样本的差异和证据输出已与 CLI 核对。交付改动仅在本任务目录内，无提交。
