# ORG-1A: mechanics for the org design (docs/ORG.md) in loomd/CLI
Read docs/ORG.md first, then the four answers it cites in /Users/sun/.loom-next/runs/loom-next/briefing (ANSWER-t13n-org.md, ANSWER-t4c-org.md, ANSWER-t17w-roles-ratio.md, ANSWER-t17g-roles-ratio.md).
1. Super-priority delivery: messages from Super (unmanaged caller or role=super) to any role jump ahead of queued worker/wave messages; if a wave is pending, deliver one combined turn with the Super message first and clearly separated. Tests for ordering and no starvation of waves.
2. Reviewer role: loom spawn reviewer (read-only intent, short-lived, one question, max duration default 30 min then auto-stop + result relayed to the spawning role); counts outside worker capacity; tests.
3. Worker capacity: default 3, hard cap 4 (was 5).
4. Succession guard: refuse leader rotation while an auditor rotation is in progress for the same project (and vice versa) until the successor is bound and its first report verified; record rotation history in the index; loom state shows it.
5. Fact-check of first reports: after a successor's (or any senior role's) turn, extract cited git SHAs, file paths and test/metric names from its reply; verify mechanically against the repo (git cat-file, path exists); unknown ones produce a 'fact-miss' notice to the supervising role (Auditor for Leader, Leader for Auditor). Also run on worker replies, reported via evidence.
6. Drift signals (to Auditor only, single-edge, coalesced): card budget (from card or policy) exceeded by actual git net lines; budget raised twice; test/compile wall time > 2x the project median for the same command; plan file (PLAN*.md in the task dir) growing beyond a policy limit; same failure class twice in a task; fact-miss. Configurable in policy.json.
7. loom status --project DIR: mechanical one-screen board (active roles and their state, current waves/cards, blocked items, drift/fact-miss notices, last merges, cost split) so Super/Auditor never need to ask the busy Leader.
8. Remove keepAlive from policy schema/examples entirely.
