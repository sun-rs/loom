# ROT-SELF-1 — rotation is self-service via the loom skill, not a Super chore

User ruling 2026-11-26: "换班应该是一个 skill，里面记录了怎么拉一个自己一样的 cli/model/effort，并且怎么把自己的工作 handoff 过去，而不是靠 Super 去换。" Base: main after ROT-PASTE-1.

1. **One command for the role itself**: `"$LOOM_BIN" rotate --self [--reason R]` (name may differ; keep `spawn --handover-from` working). It reads the caller's own session record (role, cli, model, effort, mode, cwd, project, tab) and starts an identical successor; the role never needs to know or type its model. Override flags only for Super (`--cli/--model/--effort`), and model changes still follow the policy (no quota-based auto-switching).
2. **Handoff = loomd facts + the role's own judgment**: loomd builds the factual part as now (open cards/waves, pending deliveries, in-flight results, last gate verdicts with paths, ledger paths, memory index). Before calling rotate, the outgoing role writes a short judgment note (≤ ~60 lines: current intent, decisions in progress, open concerns, what it would do next, what NOT to redo) to the path loomd gives it; loomd embeds/links it in the content-addressed brief. Template lives in the skill.
3. **When**: loomd's rotation signal (context over threshold, rotateAt gate boundary) is delivered to the role itself, attached to its next existing delivery (no extra wake). The role rotates at the next safe point (no turn in flight on its side, cards settled or explicitly listed as in-flight in the note). If it hasn't rotated after N further turns or a time bound, loomd escalates: Leader → Auditor, Auditor → Super.
4. **Oversight**: Leader rotation is reported to the Auditor (one line via the gate/notice channel, no extra wake beyond the existing budget); Auditor rotation is reported to Super. Super only acts on failures (the successor failed ack → predecessor keeps working and gets the failure reason in its next delivery so it can retry once itself; second failure → escalate).
5. **Skill text**: update the loom skill (Leader and Auditor sections) with: when to rotate, the one command, the note template, what to do on failure, and that unattended roles must not wait for Super to do it. Update role launch prompts accordingly.
6. Tests: self-rotate for agy Leader and Claude Auditor in isolated fixtures (real TUI where feasible, as ROT-PASTE-1 did) incl. failure → predecessor retry once → escalate; identical runtime inherited; note embedded; signal delivered on an existing delivery only.
