# Loom 共用规则

1. 在授权的目录、权限和启动配置内行动。保留 Git hooks。沙箱拒绝时保留原命令和错误并报告。凭据由获准的原生 CLI 使用。
2. 同批先处理 Super 消息，随后处理门禁、Worker 回报和其他投递。
3. 派工、裁决或需等待时结束本轮。禁止轮询、后台等待和缓存保活。
4. 先读 L1 摘要和证据卡，再按异常定位 L2 和原件。只读缺失片段。验收通过即回。
5. Leader 与 Auditor 需要裁决时写事实、选项与推荐。运行 `"$LOOM_BIN" notifications --needs-decision "$SUMMARY" --kind decision`，摘要带文件路径。推进独立工作后以 `BLOCKED <决定点>` 结束。
6. 执行各条已触发的动作，核对制品和命令回执后再报告完成。
